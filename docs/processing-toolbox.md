# 空间分析工具箱

点击 header 左侧「工具」（位于「设置」左侧），在地图旁直接进行矢量分析。入口与侧栏标题均为「工具」，入口采用纯文字样式。工具以分类树显示，列表固定高 200px，搜索和树区域使用低对比度外框。默认折叠全部类别且未选中工具，点击类别查看工具，点击工具选中，再次点击取消；搜索支持中文、英文名称及别名，搜索时展开匹配类别，清空后恢复手动展开状态。

未选中工具时，不显示参数、运行区和使用说明。重新选中保留该工具本次会话参数。

侧栏采用分区工作台：搜索与工具分类树在上方，输入数据和输出设置位于参数区，字段标签与控件同行；运行按钮独立分区，使用说明位于最下方。参数区按需滚动，运行区保持可见。图层下拉框只显示名称，不显示要素数量。收藏、最近和运行记录已移除。

## 操作流程

1. 导入数据，或新建要素后保存并退出编辑模式。
2. 选择工具和输入图层；双图层工具还需选择目标图层。默认使用当前活动图层，类型不符时就地提示。
3. 设置距离、容差、分组字段或空间关系，填写结果名称，点击「运行分析」。已选中输入图层的要素时，可勾选仅使用选中的要素。
4. 结果自动加入地图并定位，标记为未保存。可将结果选为下一次分析的输入，也可使用文件菜单保存或导出。原图层保持原样。

失败时保留参数，可调整后重试。运行期间禁止重复提交和应用退出；计算在后台线程执行，界面显示等待状态。编辑模式、绘制草稿或其他弹窗未结束时不能运行。侧栏隐藏再打开保留当前参数；切换工具保留各工具的参数，仅在本次会话中保留。

## 工具

| 分类 | 工具 | 输入及结果 |
| --- | --- | --- |
| 叠加分析 | 缓冲区 | 点、线、面按正距离生成缓冲面，保留属性 |
| 叠加分析 | 裁剪 | 面与目标面的总覆盖范围裁剪，保留输入属性 |
| 叠加分析 | 相交 | 两个面图层逐对提取共同区域，保留双方属性 |
| 叠加分析 | 差异 | 从输入面扣除目标面的覆盖区域 |
| 叠加分析 | 对称差异 | 保留两侧各自独有的面区域及各自属性 |
| 叠加分析 | 融合 | 融合全部面，或按字段类型和值分组融合 |
| 空间关系 | 按位置提取 | 按相交、内部、包含、接触或不相交关系提取输入要素 |
| 空间关系 | 按位置关联统计 | 保留全部输入，添加匹配目标数量与索引 |
| 空间关系 | 最近目标 | 为每个输入添加最近目标索引与近似距离 |
| 空间关系 | 面内点计数 | 源面、目标点；统计内部和边界上的点，MultiPoint 按点计数 |
| 几何处理 | 质心 | 每个要素的平面中心；凹面或含洞面可能落在面外 |
| 几何处理 | 面内点 | 为每个面生成位于内部的代表点 |
| 几何处理 | 凸包 | 每个要素的凸包；退化几何可输出点或线 |
| 几何处理 | 包络矩形 | 每个要素的轴对齐范围；退化范围可输出点或线 |
| 几何处理 | 多部件转单部件 | 拆分 Multi 几何，面洞仍属于原面 |
| 几何处理 | 提取顶点 | 生成点及来源部件、环、顶点索引，不重复面环闭合末点 |
| 几何处理 | 面转线 | 外环和洞转成线，保留输入属性 |
| 几何处理 | 简化几何 | 以米制容差减少线、面顶点；无效结果拒绝并提示降低容差 |
| 几何处理 | 添加几何属性 | 保留几何，添加近似面积、长度；面长度为包含洞的周长 |
| 几何处理 | 合并图层 | 汇集两个图层的要素，不消除重叠或内部边界 |
| 质量与统计 | 拓扑检查 | 列出无效几何、完全重复几何和面重叠，不自动修复 |
| 质量与统计 | 图层摘要 | 展示数量、类型、字段和经纬度范围 |

拓扑报告按本次输入顺序显示从 1 开始的要素序号；界面最多展示前 100 个问题并标注完整问题数量。摘要和拓扑结果直接展示在工具箱，不生成矢量图层。

## 属性与几何规则

相交时输入属性保留，目标字段使用 `target_` 前缀；重名时继续追加下划线。关联统计、最近目标、点计数、顶点提取和量算同样追加独立字段，避免覆盖原值。量算字段为 `_zgis_area_m2` 和 `_zgis_length_m`，点计数字段为 `_zgis_point_count`。

融合仅保留分组字段和 `sourceCount`；同值同类型合并，数字 `1`、`1.0` 属于同组，字符串 `"1"` 属于另一组。字段缺失或非标量值明确报错。拆部件、提取顶点、合并图层及逐对叠加结果重新分配要素身份，避免复制原 ID 导致重复。

## 适用范围

当前为二维矢量工具箱，不包含栅格分析、批处理、模型构建器、网络分析或完整拓扑修复。含 Z/M 的图层明确拒绝；需要分析时先从导出入口生成二维副本并重新导入，不自动降维。

工作坐标统一 WGS84。空间关系、凸包、质心与面叠加使用经纬度平面，拒绝跨日期线。缓冲、简化、最近目标及量算使用局部等距圆柱近似，非测地算法；适用纬度 ±75°、经纬跨度均不超过 5°。缓冲距离和简化容差须大于 0，最多 100000 米。工程精度、大范围或高纬数据应使用适当投影与专业 GIS 引擎。

每个输入层与结果最多 10000 要素、100 万顶点；单次分析最多 100 万候选对，输入总内容及结果各限 100 MiB。生成结果逐项检查要素、顶点与字节预算，超限拒绝整次分析，不返回截断结果。PostGIS 输入只分析已加载要素，不能把读取范围当作整表。

## 实现与参考

工具箱通过纯内存桌面命令 `gis_run_analysis` 调用共享 Rust 几何引擎，不要求启动 MCP 或 Codex，不读取任意路径或提交数据库。新增分析同时进入 MCP 工具清单，Agent 入口与权限边界见 [MCP 与 Codex Agent](spatial-mcp.md)。

交互参考 [QGIS Processing Toolbox](https://docs.qgis.org/3.44/en/docs/user_manual/processing/toolbox.html) 的分类搜索与输入参数；算法用途参考 [矢量叠加](https://docs.qgis.org/3.44/en/docs/user_manual/processing_algs/qgis/vectoroverlay.html) 和 [矢量几何](https://docs.qgis.org/3.44/en/docs/user_manual/processing_algs/qgis/vectorgeometry.html)。zGIS 使用现有 Rust 引擎及上述计算边界，不宣称 QGIS 算法或精度完全等价。
