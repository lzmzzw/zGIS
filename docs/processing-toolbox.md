# 空间分析工具箱

点击 header 左侧「工具」（位于「设置」左侧），在地图旁直接进行矢量分析。入口与侧栏标题均为「工具」，入口采用纯文字样式。搜索与分类树区域合计固定高 288px，工具列表独立滚动。默认折叠全部类别且未选中工具，点击类别查看工具，点击工具选中，再次点击取消；搜索支持中文、英文名称及别名，搜索时展开匹配类别，清空后恢复手动展开状态。

未选中工具时，不显示参数、运行区和使用说明。重新选中保留该工具本次会话参数。

侧栏保留上方工具选择、中部参数配置、下方执行按钮的结构。细线配合留白分隔：工具区到参数标题间隔 36px，输入与输出分组间隔 32px。参数区显示工具用途短句，字段标签与控件同行；使用说明默认折叠，位于参数末尾、执行区之前。参数与说明一起滚动，执行区固定在底部。深浅主题均使用中性配色；工具栏和 Agent 栏等宽并同步调整，详见 [界面设计约定](interface-design.md)。图层下拉框只显示名称，不显示要素数量。收藏、最近和运行记录已移除。

## 操作流程

1. 导入数据，或新建要素后保存并退出编辑模式。
2. 选择工具和输入图层；双图层工具还需选择目标图层。默认使用当前活动图层，类型不符时就地提示。
3. 设置距离、容差、分组字段或空间关系，填写结果名称，点击「运行分析」。已选中输入图层的要素时，可勾选仅使用选中的要素。
4. 结果自动加入地图并定位，标记为未保存。可将结果选为下一次分析的输入，也可使用文件菜单保存或导出。原图层保持原样。

失败时保留参数，可调整后重试。运行期间禁止重复提交和应用退出；计算在后台线程执行，界面显示等待状态。编辑模式、绘制草稿或其他弹窗未结束时不能运行。侧栏隐藏再打开保留当前参数；切换工具保留各工具的参数，仅在本次会话中保留。

| --- | --- | --- |
| 叠加分析 | 缓冲区 | 点、线、面按正距离生成缓冲面，保留属性 |
| 叠加分析 | 裁剪 | 面与目标面的总覆盖范围裁剪，保留输入属性 |
| 叠加分析 | 相交 | 两个面图层逐对提取共同区域，保留双方属性 |
| 叠加分析 | 差异 | 从输入面扣除目标面的覆盖区域 |
| 叠加分析 | 对称差异 | 保留两侧各自独有的面区域及各自属性 |
| 叠加分析 | 融合 | 融合全部面，或按字段类型和值分组融合 |
| 空间关系 | 按位置提取 | 按相交、内部、包含、接触或不相交关系提取输入要素 |
| 空间关系 | 按位置关联统计 | 保留全部输入，添加匹配目标数量与索引 |
| 空间关系 | 最近目标 | 为每个输入添加最近目标索引；点对用椭球距离，其他几何为局部近似 |
| 空间关系 | 面内点计数 | 源面、目标点；统计内部和边界上的点，MultiPoint 按点计数 |
| 几何处理 | 质心 | 每个要素的平面中心；凹面或含洞面可能落在面外 |
| 几何处理 | 面内点 | 为每个面生成位于内部的代表点 |
| 几何处理 | 凸包 | 每个要素的凸包；退化几何可输出点或线 |
| 几何处理 | 包络矩形 | 每个要素的轴对齐范围；退化范围可输出点或线 |
| 几何处理 | 多部件转单部件 | 拆分 Multi 几何，面洞仍属于原面 |
| 几何处理 | 提取顶点 | 生成点及来源部件、环、顶点索引，不重复面环闭合末点 |
| 几何处理 | 面转线 | 外环和洞转成线，保留输入属性 |
| 几何处理 | 简化几何 | 以米制容差减少线、面顶点；无效结果拒绝并提示降低容差 |
| 几何处理 | 添加几何属性 | 保留几何，添加近似面积、长度；面长度为包含洞的周长 |
| 几何处理 | 合并图层 | 汇集两个图层的要素，不消除重叠或内部边界 |
| 质量与统计 | 拓扑检查 | 列出无效几何、精确重复、XY 拓扑重复及面重叠，不自动修复 |
| 质量与统计 | 图层摘要 | 展示数量、类型、字段和经纬度范围 |
| 质量与统计 | 剔除空或无效几何 | 保留有效要素副本，报告剔除数量和原因；不修复、不删除重复项 |

清理工具仅处理当前可加载的图层，不放宽文件导入校验；输入中的空几何与无效几何可被剔除，全部剔除时生成空结果。跨日期变更线等能力限制使分析失败，不作为坏数据删除。原图层不变，保留要素的坐标、XYZ 和属性不变；移除原因最多列出 100 项，并明确总数与明细是否截断。

拓扑报告按本次输入顺序显示从 1 开始的要素序号；界面最多展示前 100 个问题并标注完整问题数量。摘要和拓扑结果直接展示在工具箱，不生成矢量图层。

点击「定位问题」会联动输入图层的属性记录，并高亮相关要素；面重叠高亮双方完整几何。无效几何只联动记录，不强制缩放。定位按本次分析的输入子集映射原要素，源图层内容变化或移除后旧定位失效，须重新检查；样式变化不影响定位。

桌面与 Web 共用结果说明：展示本次实际输入范围、输入与目标数量、矢量输出数量及适用的请求参数。核心返回计算模型、距离单位或移除统计时，说明区展示这些信息；旧结果缺少元数据时不推断精度或完整性。局部近似与移除明细截断会单独提示，模型、单位、移除数量和关键限制同时保留在结果图层说明中。说明不记录源路径或数据库身份，也不替代实际结果的保存与导出。

## 属性与几何规则

相交时输入属性保留，目标字段使用 `target_` 前缀；重名时继续追加下划线。关联统计、最近目标、点计数、顶点提取和量算同样追加独立字段，避免覆盖原值。量算字段为 `_zgis_area_m2` 和 `_zgis_length_m`，点计数字段为 `_zgis_point_count`。

融合仅保留分组字段和 `sourceCount`；同值同类型合并，数字 `1`、`1.0` 属于同组，字符串 `"1"` 属于另一组。字段缺失或非标量值明确报错。拆部件、提取顶点、合并图层及逐对叠加结果重新分配要素身份，避免复制原 ID 导致重复。

## 适用范围

支持 XY 和 XYZ 输入输出，不包含栅格分析、批处理、模型构建器、网络分析或完整拓扑修复；M/ZM 仍不支持。三分量 GeoJSON 坐标按 XYZ 解释，高程必须为有限数值。

空间计算仍使用 XY，高程不参与拓扑、距离或面积计算。输入几何不变时完整保留 XYZ；拆部件、提取顶点和面转线直接保留原坐标；简化保留所选原顶点的高程。其他派生几何按本要素的 XY 匹配原顶点；面叠加使用与引擎一致的量化网格匹配，避免数值舍入造成高程丢失，高程无法确定的新点填 0，不插值、不换算垂直基准。裁剪、相交和差集以输出要素所属输入为高程来源，目标仅提供平面范围；对称差两侧分别使用各自来源。融合只匹配本分组的原顶点，同一 XY 对应多个不同高程时填 0。输入几何含 XYZ 时其派生几何全为 XYZ，二维顶点补 0；合并图层只要任一输入含 XYZ，结果全部升为 XYZ，已有高程保留。纯 XY 输入保持二维。完全重复几何检查包含 Z；环起点/方向不同但 XY 相等单独标为拓扑重复，面重叠按 XY。无效几何单独报告，不参与成对检查。

XYZ 结果通过 GeoJSON 或 WKT 保存，并在工作副本恢复中保留；XY CSV 和 SHP 导出仍只支持二维，不能静默丢弃高程。

工作坐标统一 WGS84。空间关系、凸包、质心与面叠加使用经纬度平面，拒绝跨日期线。最近目标的 Point 对使用 WGS84 椭球测地距离；其他几何对按各自范围进行局部等距圆柱近似。缓冲、简化与量算仍使用局部等距圆柱近似；所有近似度量适用纬度 ±75°、经纬跨度均不超过 5°，不代表测绘级精度保证。缓冲距离和简化容差须大于 0，最多 100000 米。工程精度、大范围或高纬数据应使用适当投影与专业 GIS 引擎。

每个输入层与结果最多 10000 要素、100 万顶点；相交类操作和拓扑使用 R-tree 按实际包络候选计数，最多 100 万对；纯 Point 最近目标使用索引并按实际椭球距离计算次数限制，非点 nearest/disjoint join 仍按需处理的全配对限制。局部掩膜、相交、空间关系、拓扑、融合、缓冲和非点最近距离另限累计处理 1000 万工作顶点（缓冲按输入顶点的 64 倍估算）。输入总内容及结果各限 100 MiB。生成结果逐项检查要素、顶点与字节预算，超限拒绝整次分析，不返回截断结果。PostGIS 输入只分析已加载要素，不能把读取范围当作整表。

## 实现与参考

工具箱通过纯内存桌面命令 `gis_run_analysis` 调用共享 Rust 几何引擎，不要求启动 MCP 或 Codex，不读取任意路径或提交数据库。新增分析同时进入 MCP 工具清单，Agent 入口与权限边界见 [MCP 与 Codex Agent](spatial-mcp.md)。

交互参考 [QGIS Processing Toolbox](https://docs.qgis.org/3.44/en/docs/user_manual/processing/toolbox.html) 的分类搜索与输入参数；算法用途参考 [矢量叠加](https://docs.qgis.org/3.44/en/docs/user_manual/processing_algs/qgis/vectoroverlay.html) 和 [矢量几何](https://docs.qgis.org/3.44/en/docs/user_manual/processing_algs/qgis/vectorgeometry.html)。zGIS 使用现有 Rust 引擎及上述计算边界，不宣称 QGIS 算法或精度完全等价。

## 验证

执行 `pnpm test`、`pnpm build`、`pnpm exec playwright test tests/processing-toolbox.spec.ts`。载入 `scripts/msvc-environment.ps1` 后执行 `cargo test --manifest-path src-tauri/Cargo.toml --lib --locked`。

原生隔离验证：创建 `output/processing-smoke.config.json`，内容为 `{"identifier":"com.personal.zgis.processing-smoke"}`；载入 MSVC 后执行 `pnpm tauri build --no-bundle --config output/processing-smoke.config.json`，再执行 `node scripts/processing-native-smoke.mjs`。脚本核对隔离标识，用生成数据验证面相交、属性保留、质心→缓冲→量算、拓扑报告和源图层保留；同时核验 XYZ 输入、高程保留、新增点 Z=0 和恢复快照；报告位于 `output/processing-native/report.json`。安装验证仍遵守 README 的包外安装流程。

工具箱与 MCP 共用 2 个计算槽位及 120 秒协作式截止时间。分析中可点击取消，界面等待真实任务结束后恢复；已经完成的任务不会显示为取消成功。单次底层几何调用无法即时中断。详见 [运行时边界](analysis-runtime.md)和[前端性能与恢复机制](frontend-performance.md)。
