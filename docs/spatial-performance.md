# 空间计算性能与边界

空间内核的可复现基准位于 `src-tauri/src/spatial.rs`。基准使用确定性合成数据、release 编译和 20 次重复测量，包含输入解析、计算、结果构造及输出校验。构建耗时不计入样本；测量结果不能代表任意真实图层或整机内存峰值。

## 已实现优化

- `intersection` 直接向一次构造的结果属性表插入目标字段，保留原有 `target_` 前缀、冲突加下划线、嵌套值及空属性语义。不会因每个目标字段重复克隆整张属性表。
- `dissolve` 按空间位置排序后逐层成对归并，减少累积大面反复参与布尔运算。包络严格分离的部分直接组合；接触或重叠仍调用几何引擎。XYZ 映射随归并分支保存，仅在布尔运算时按同一量化适配器更新。同一 XY 的冲突高程和新生成节点按现有规则置零，分离组合不移动原坐标。计算顺序变化可能造成浮点末位与环顺序变化；以面积、孔洞和拓扑语义验证，不要求坐标文本逐字相同。
- 纯 `Point` 的 `nearest` 使用三维单位球 R-tree 按弦长枚举候选，再用 WGS84 椭球距离求答案。球面坐标由测地经纬度构造；WGS84 最小曲率半径约为 6,335,439.327 米，取更小的 6,335,000 米乘弦长作为保守下界，并留 1 微米浮点裕量。只有候选下界严格超过当前最优距离才停止，因此经纬度跨日期线、高纬度与极点不会因二维经纬度排序漏掉更近点。精确距离相等时选择原目标索引较小的要素。
- `nearest` 结果 `analysis.exactDistanceEvaluations` 提供实际精算次数。纯点输入不再按笛卡尔积预先拒绝，而按实际精算次数限制；非纯点仍受全配对预检约束并保留成对局部投影近似。

## 计算保护

现有 10,000 要素、1,000,000 顶点、100 MiB 输出上限继续生效。空间关系、点计数、交集、拓扑检查、缓冲及合并加入累计工作检查。关系和叠加累计计入每次参与计算的顶点，归并计入中间结果再次参与的顶点；超过 10,000,000 即返回错误，不输出截断结果。缓冲按每个输入顶点 64 个工作单位计费，此项为复杂度预算，不能视为底层内存用量的严格估计。纯点最近邻最多进行 1,000,000 次距离精算；大量重复点或难以剪枝的数据仍可能触发上限。

要素、候选对、归并、坐标检查及输出环节调用共享运行时的取消/超时检查。输出大小和几何校验也在 panic 捕获边界内，校验失败或取消不会把未经验证的部分结果交给调用者。取消是协作式；单次 `geo` 布尔运算、有效性校验或缓冲库调用执行期间不能强行中断，只有返回检查点后才停止。顶点预算也不是对某个极端自交几何的 CPU 时间或峰值内存的严格上限。

## 验证与基准入口

Windows PowerShell：

```powershell
. ./scripts/msvc-environment.ps1
cargo test --manifest-path src-tauri/Cargo.toml --lib spatial::tests
cargo test --manifest-path src-tauri/Cargo.toml --lib --release spatial_performance_baseline -- --ignored --nocapture --test-threads=1
cargo test --manifest-path src-tauri/Cargo.toml --lib --release spatial_preparation_profile -- --ignored --nocapture --test-threads=1
```

功能回归覆盖全域随机点、极区、日期线和重复点对椭球穷举的对照，10,000×10,000 点索引查询、密集等距候选超限、宽属性字段冲突、XYZ、孔洞、面积、取消与工作预算。基准为 ignored 测试，普通测试不会暗中跑性能测量。

2026-10-11 在同一 Windows x64、AMD Ryzen 9 7950X 主机上测量，基线为 `ed0788e` 空间算法加同一测试夹具。每项先预热一次，再测 20 次；下表为中位数，单位毫秒。

| 场景 | 优化前 | 优化后 | 前/后比值 |
| --- | ---: | ---: | ---: |
| 400 个分离正方形 dissolve | 63.970 | 8.105 | 7.89 |
| 12 个面与 600 字段面 intersection | 140.613 | 5.408 | 26.00 |
| 300 源点、700 目标点 nearest | 62.581 | 3.318 | 18.86 |

对应 p95 分别为 64.917→8.326、143.093→5.785、63.082→3.545 毫秒。原始样本由测试输出 JSON，任务测量日志保存在忽略目录 `output/performance-20261011/`，不进入发布包。单机合成数据收益不能推导为所有数据上的固定倍数。

准备阶段独立测量中，10,000 点的一次 decode 中位数为 10.439 毫秒、球面索引构建为 2.360 毫秒；同一 10,000×10,000 点任务完整 nearest 为 137.215 毫秒，仅精算 10,000 次。该场景索引构建占比约 1.7%，因此本批不为其新增持久几何/索引副本。若后续复杂面、重复分析证明准备开销成为主因，应使用已有图层版本作为键并与全局内存预算共同淘汰，避免为生成缓存键重新序列化整层。此方向尚未实施，当前测量也未覆盖真实大图层峰值内存。
