# zGIS 0.3.6

本版包含 [0.3.5](0.3.5.md) 的图层保存、数据库同步及地图定位修复，调整 Windows 页面回归的运行方式和备份失败验证。

- CI 页面回归使用已构建的生产产物，通过 `vite preview` 在固定端口启动服务。此前使用开发服务器，云端页面和解析 Worker 的模块加载可能耗尽导入、重启测试的等待时间。
- 备份失败测试先确认旧版恢复副本已成功升级，再注入写入失败；核对失败前最后一次成功保存的快照保持不变，并继续验证退出被阻止和重试成功。
- 保留失败截图、trace、错误上下文和 Vite 日志，不增加正式回归的等待时限或自动重试次数。
- 样式与菜单测试按配置的应用地址拦截第三方网络，允许使用独立端口验证生产产物。
- 菜单键盘测试等待展开后的首项焦点就绪，再验证 End 与 Tab，避免异步焦点安排和测试输入重叠。

提供 Windows x64 NSIS 安装包、macOS ARM64 DMG、app 压缩包及统一 SHA256SUMS.txt。macOS 使用 ad-hoc 签名，未使用 Developer ID 签名和 Apple 公证。
