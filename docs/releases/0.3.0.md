# zGIS 0.3.0

本版增加 Apple Silicon macOS 支持，并完善矢量编辑、源文件保存与窗口行为。安装包提供 Windows x64 NSIS、macOS ARM64 DMG 和 app 压缩包，统一校验文件为 SHA256SUMS.txt。

## macOS

- 支持 macOS 14 及以上的 Apple Silicon；GitHub Actions 使用 macos-15 ARM64 runner 构建 aarch64-apple-darwin，不包含 Intel 或 Universal 包。
- 标题栏采用左侧系统原生红黄绿按钮，支持最小化和系统全屏；界面与终端使用 macOS 系统字体，前端构建兼顾 Safari 17。
- Command+S 保存，Command+Z 撤销，Command+Shift+Z 重做；Backspace 可删除选中要素。原生编辑菜单提供剪切、复制、粘贴与全选；窗口关闭、Command+W、Command+Q 和 Dock 退出经过编辑状态确认。
- 数据库密码与底图配置使用钥匙串保护的 AES-256-GCM 密钥加密保存；MCP 固定令牌保存在钥匙串，包内提供 macOS 认证助手。
- Finder 启动时补充 Homebrew 与 Cargo 的常用 CLI 路径；关闭 Agent 会话时清理所属 PTY 进程组。Codex CLI 仍需单独安装并登录。

## 编辑与保存

- 调整矢量编辑工具顺序与反馈，退出编辑由独立入口处理，保存编辑保留当前会话。
- 恢复工作区时保留来源路径与 SHA-256 指纹；来源未被外部修改时可直接保存回原文件，缺失或发生冲突时要求另存。
- 完善绘制、顶点编辑、属性草稿和关闭确认的恢复回归；Windows 最大化与还原按钮随原生窗口 resize 更新图标。

## 构建与限制

双平台检查和构建全部成功后，才聚合产物、生成校验文件并公开 Release；失败保留草稿，拒绝覆盖已发布版本。macOS 包使用 ad-hoc 签名，未使用 Apple Developer ID 签名和公证，首次打开仍受 Gatekeeper 检查。CI 构建与浏览器模拟不等于 Mac 原生安装、钥匙串和 WKWebView 交互验收。

文件格式、坐标精度、分析预算与数据库写回限制继续见 [README](../../README.md)。本版未增加数据库直连 MCP 或自动更新。
