# zGIS 0.3.7

本版包含 [0.3.6](0.3.6.md) 的功能与修复，消除异步页面回归对模拟响应耗时的依赖。

- 底图预览取消测试原先假定模拟瓦片的 1 秒延迟足够完成所有检查。现在由测试在取消之后显式释放瓦片响应，验证请求期间不可重复提交、可以取消，以及迟到响应不会保存底图。
- 底图超时测试使用可控时钟，核对 7999 毫秒时仍在等待、8000 毫秒时保存服务并提示预览不可用；随后释放瓦片响应，确认不会补写预览或再次保存。
- 分析失败、接受取消、拒绝取消和检查更新的迟到响应测试使用同样的显式响应控制，避免慢速运行环境错过中间状态或让测试提前通过。

正式页面回归仍使用生产预览、3 workers 和 30 秒单项时限，不增加自动重试。产品保存、取消和超时逻辑未变。

提供 Windows x64 NSIS 安装包、macOS ARM64 DMG、app 压缩包及统一 SHA256SUMS.txt。macOS 使用 ad-hoc 签名，未使用 Developer ID 签名和 Apple 公证。
