# zGIS 0.3.8

关于页新增应用内下载更新。Windows 可在下载完成后直接覆盖安装并重启。

- 从本仓库正式 GitHub Release 下载对应平台安装包，核对 SHA256SUMS.txt；安装前重新校验缓存，拒绝损坏的包、降级和同版重装。
- 下载期间阻止重复提交，失败可重试，当前安装保持可用。
- Windows 覆盖当前程序目录前先保存工作区恢复副本和底图配置；编辑中的会话沿用退出确认，取消或保存失败不启动安装。应用退出后执行安装并自动重启；存在其他 zGIS 实例时停止安装，不强制终止编辑会话。
- macOS ARM64 可下载校验后的 DMG 并打开，替换应用仍需手工完成；未宣称通过 macOS 自动覆盖安装验收。

提供 Windows x64 NSIS 安装包、macOS ARM64 DMG、app 压缩包及 SHA256SUMS.txt。SHA-256 用于下载完整性检查，未新增独立发行签名；macOS 仍使用 ad-hoc 签名，未使用 Developer ID 签名和 Apple 公证。
