# zGIS 0.3.3

本版完善图层来源管理与编辑保存链路，提供 Windows x64 NSIS 安装包、macOS ARM64 DMG、app 压缩包及统一 SHA256SUMS.txt。

## 图层来源与保存

- 图层栏明确区分「工作区」「文件」「数据库」来源，并显示对应保存目标。
- 工作区图层首次保存时选择 GeoJSON、CSV WKT、CSV X/Y 或 SHP 文件组、目标坐标系和路径；成功绑定后直接回写来源文件。
- SHP 文件组和 ZIP 图层回写校验整组指纹，失败回滚，ZIP 保留其他成员；来源外部变化时保留编辑并阻止覆盖。

## 数据库恢复与冲突同步

- 数据库图层重启后保留原数据源配置 ID、表结构、读取范围和记录基线，按原源重连并刷新原表，仍保持数据库来源身份。
- 连接失败时保留本地编辑并提示重连，不会自动转为文件保存；保存前再次核对表结构和原记录。
- 同一记录发生本地和数据库双重修改时逐条展示两个版本，由用户选择保留本地或数据库版本；选择期间远端再次变化时要求重新处理。

## 验证与限制

前端单元测试、页面回归、Rust 测试、类型检查、构建和原生文件回写 smoke 已在 Windows 开发环境通过。macOS 包使用 ad-hoc 签名，未使用 Developer ID 签名和 Apple 公证；真实数据库连接仍需在目标环境验收。
