# zGIS 0.3.1

本版交付 Apple Silicon macOS 支持及矢量编辑改进，包含 [0.3.0 说明](0.3.0.md) 中的全部功能。0.3.0 标签的 macOS 编译和 Rust 测试通过，但 Unix 文件保存分支的一处多余引用未通过 Clippy，未公开发行；0.3.1 修复该静态检查问题并重新执行双平台检查、构建和发布。

提供 Windows x64 NSIS 安装包、macOS ARM64 DMG、app 压缩包及统一 SHA256SUMS.txt。macOS 要求 14 及以上、Apple Silicon，采用左侧系统原生红黄绿按钮、系统字体、Command 快捷键和钥匙串加密存储。macOS 包使用 ad-hoc 签名，尚未使用 Apple Developer ID 签名和公证，首次打开仍受 Gatekeeper 检查。

平台检查和打包全部成功后才公开发行。CI 构建及浏览器回归不替代 Mac 原生安装、钥匙串授权和 WKWebView 交互验收。详细功能与限制见 [README](../../README.md)。
