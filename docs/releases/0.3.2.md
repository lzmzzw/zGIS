# zGIS 0.3.2

本版增加 Apple Silicon macOS 支持，提供 Windows x64 NSIS 安装包、macOS ARM64 DMG、app 压缩包及统一 SHA256SUMS.txt。

## macOS 支持

- macOS 14 及以上、Apple Silicon，GitHub Actions 原生 ARM64 打包；不包含 Intel 或 Universal 包。
- 标题栏左侧使用系统原生红黄绿按钮，支持最小化与系统全屏；界面和终端使用 macOS 系统字体，前端兼顾 Safari 17。
- Command+S 保存、Command+Z 撤销、Command+Shift+Z 重做，Backspace 删除选中要素；原生菜单支持剪切、复制、粘贴、全选，窗口关闭及 Command+W / Command+Q / Dock 退出经过编辑状态确认。
- 数据库密码和底图配置采用钥匙串保护的 AES-256-GCM 密钥加密保存；MCP 固定令牌保存在钥匙串，提供包内 macOS 认证助手。
- Finder 启动补充 Homebrew / Cargo 常用 CLI 路径；停止 Agent 会话时清理所属 PTY 进程组。Codex CLI 需单独安装并登录。

## 编辑与稳定性

- 调整矢量编辑工具顺序和反馈，保存编辑保留会话，独立入口退出编辑。
- 恢复时保留来源路径与 SHA-256 指纹；来源未被外部修改时直接保存回原文件，缺失或冲突时要求另存。兼容缺少 dirty 字段的旧恢复副本。
- 完善绘制、顶点、属性草稿与关闭确认的恢复回归；Windows 最大化和还原图标随原生 resize 更新。
- 修复 Unix 文件保存分支的 Clippy 问题，并让空图层恢复测试等待快照写入后再断言。0.3.0 / 0.3.1 标签未公开发行。

双平台检查和打包全部成功后才公开 Release。macOS 包使用 ad-hoc 签名，未使用 Apple Developer ID 签名和公证，首次打开受 Gatekeeper 检查。CI 与浏览器回归不替代 Mac 原生安装、钥匙串授权及 WKWebView 交互验收。详细边界见 [README](../../README.md)。
