# zGIS 0.3.5

本版包含 [0.3.4](0.3.4.md) 的图层来源保存与数据库同步功能，修复属性表搜索与地图定位之间的状态竞态。

- 搜索结果生效后，从地图选中被筛选排除的记录，会立即清空搜索和实际筛选条件，并定位到该记录所在页；此前可能清空搜索框后仍停留在第 1 页。
- 地图选择回归先确认防抖筛选已生效，再检查跨页定位，并等待选中轮廓的实际渲染和取消选择状态，避免依赖固定等待时间。
- Windows CI 页面回归失败时保留截图、trace、错误上下文及 Vite 日志，方便定位失败现场。

提供 Windows x64 NSIS 安装包、macOS ARM64 DMG、app 压缩包及统一 SHA256SUMS.txt。macOS 使用 ad-hoc 签名，未使用 Developer ID 签名和 Apple 公证。
