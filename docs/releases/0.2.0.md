# zGIS 0.2.0

本版集中修复大图层的重复计算、连接间阻塞、异常文件崩溃及恢复草稿保真问题，并完善构建、安装和发布门禁。

## 相比 0.1.0 的功能变化

- 应用内增加 22 项空间分析工具与分类目录，结果作为独立图层继续使用；分析支持 XYZ 输入，按 XY 计算并保留已知高程。
- 工具与 Agent 侧栏支持停靠与拖动宽度，导入、导出、设置页面采用紧凑布局。
- 统一文件与数据库图层入口、记录与字段编辑；新增 SHP 文件夹另存、图层显示名和来源文件重命名。
- 属性表支持列宽、顺序与独立要素定位；铅笔按钮统一切换编辑模式，单元格修改通过应用/取消确认。
- 完善移除未保存图层、退出和跨进程编辑恢复，避免把已放弃的会话带入快照。

## 性能

- 地图复用样式，批量构建要素空间索引；选择变化不再触发全部图层同步。地图只保存几何和标识，避免复制业务属性及同名 `geometry` 属性覆盖地图几何。
- 属性表缓存字段、搜索、选中记录和字段摘要；鼠标位置更新按动画帧合并。
- Worker 使用紧凑的可转移缓冲区，保留调用方输入供重试；恢复日志与原生备份复用同一快照，MCP 同步跳过过期的待执行状态。
- PostGIS 与 MySQL 使用每连接独立锁；一个连接的慢查询不再阻塞其他连接、连接创建与断开。
- PostGIS 逐行构建完整要素与提交基线，避免先聚合整批行；完整响应受 100 MiB 预算和读取超时保护，超限整体拒绝。单行驱动解码与服务端缓冲仍可能有更高峰值。
- 空间关系、面叠加和拓扑检查先筛选包围盒；最近邻计算减少几何复制。输入规模与要素对数限制继续生效，稠密重叠数据仍可能耗时。
- JSON 预算检查和图层指纹使用计数写入与流式哈希；GeoJSON 按所有权取出要素，SHP 导出逐要素转换；底图预览复用 HTTP 客户端与连接池。

## 稳定性与资源边界

- EPSG:3857 GeoJSON 的畸形或非有限坐标返回错误，避免解析崩溃；高精度 SHP 数值在转换前检查，拒绝静默舍入。
- 独立 SHP 文件组按组件合计检查 100 MiB 输入上限；GeoJSON 在取得要素前检查 10 万条限制。
- Worker 的同步传输异常、错误消息、取消和正常完成均释放资源。
- 恢复保留属性草稿的 NULL 意图；应用草稿写入 NULL，重新输入则取消该意图。
- 数据库连接目录有每引擎 8 连接上限，每连接排队最多等待 35 秒；断开后排队请求失效，执行中的操作按原有事务与超时边界结束。
- MCP 服务绑定启动代次，旧 HTTP 连接不能继承重启后的服务；待导入结果单独限制总大小 100 MiB，工具目录和初始化版本来自统一来源。

## 构建与安装

四处版本（package、Cargo、Cargo.lock、Tauri）统一为 0.2.0。构建增加版本一致性、未使用代码和 Rust clippy 检查；安装器路径按配置版本解析。包外完整回归入口为：

```powershell
pwsh -File scripts/build.ps1
pwsh -File scripts/install.ps1 -Smoke -FullSmoke -Launch
```

GitHub 标签发布从本文件读取发行说明，测试成功后才构建安装包并公开 Release；安装包同时提供 SHA256SUMS.txt。

## 兼容与限制

现有工作区恢复格式、文件格式、编辑入口和 Tauri IPC 参数保持兼容。数据库源恢复为本地副本；本版没有增加数据库直连 MCP、源文件自动覆盖或自动更新。

坐标与测地精度、SHP 字段限制、分析规模和数据库加载上限继续按 [README](../../README.md) 与 [工具箱说明](../processing-toolbox.md) 执行。真实 PostGIS/MySQL 的 TLS、DDL 与并发集成未在本次本地夹具测试中验证。模块职责与后续拆分范围见 [代码结构](../architecture.md)。
