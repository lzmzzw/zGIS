# zGIS 0.4.1

本版本完善已有矢量分析、图层显示和结果查阅，保持轻量桌面与纯静态 Web 的定位。

- 新增按属性条件提取和字段分组统计，支持严格类型条件、组合条件、分组与数值指标；数字文本不自动转换，统计返回只读表格。
- 空间连接支持对匹配目标要素做属性聚合，按目标要素计数，MultiPoint 不拆成多条记录；无匹配时计数为零、数值指标为空。
- 拓扑检查报告支持定位问题要素，便于从报告返回地图核查。
- 图层支持按字段唯一值分类着色和字段标注；显示配置保留在工作区，不修改数据文件属性。
- 图层可展开图例，查看类别、分级区间及当前已加载要素的数量；右侧检查器提供字段概览与样式页签。
- 字段概览区分有效、null、缺失和数据类型，提供纯数值统计、直方图及常见值；超出预算明确提示，不展示部分统计。
- 新增等间隔、分位数和手动断点分级着色，修改即时预览，应用后保存，取消或关闭放弃草稿。
- 命令面板统一发现已有图层操作和分析工具。选择分析工具只打开参数配置，仍需用户运行；本次显示与命令面板不新增 MCP 工具。
- 分析元数据、输入校验和桌面/Web 共用逻辑进一步统一，保持现有结果类型、取消与规模限制。当前提供 25 项矢量分析与统计工具。

桌面与 Web 共用图层显示和分析能力；Web 仍不包含数据库、AI 或 MCP，关闭或刷新前须下载需要保留的数据。字段概览与图例只描述当前已加载数据，不代表数据库全表。

发行产物继续包含 Windows x64 安装包、macOS ARM64 DMG 与 app 压缩包、Web 静态资源 ZIP及统一 SHA-256 校验文件。macOS 使用 ad-hoc 签名，尚未提供 Developer ID 签名与 Apple 公证。使用与边界见 [图层显示](https://github.com/lzmzzw/zGIS/blob/v0.4.1/docs/layer-display.md)和[空间分析工具箱](https://github.com/lzmzzw/zGIS/blob/v0.4.1/docs/processing-toolbox.md)。
