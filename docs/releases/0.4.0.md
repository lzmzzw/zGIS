# zGIS 0.4.0

同一项目新增纯静态 Web 版，用户可在浏览器本地导入空间文件、显示图层并运行空间分析，无需安装桌面应用或部署计算后端。

- 支持 GeoJSON、CSV（WKT 或 X/Y）与 SHP ZIP 导入，提供多图层显隐、颜色、透明度、范围定位和属性搜索、选择、定位。
- 提供 OpenStreetMap 街道底图和无底图模式；文件内容不上传，底图瓦片仍通过网络获取。
- 现有 22 项分析工具通过 Rust WebAssembly 在 Worker 中运行，结果加入独立图层，可继续分析或下载 GeoJSON、CSV、SHP ZIP；支持任务取消和时间预算。
- 桌面与 Web 共用 Rust 空间核心和 SHP 导出规则，沿用现有坐标精度、XYZ 保留、字段保真与规模限制。
- Web 使用独立构建入口，排除数据库、AI、MCP、终端和桌面更新能力；工作区仅在当前页面内存中，关闭或刷新前须下载需要保留的结果。
- 新增 Web 静态资源 ZIP，与 Windows x64、macOS ARM64 安装产物一同发布，纳入统一 SHA-256 校验。支持静态托管根目录与子目录部署。

使用、构建、部署与浏览器边界见 [Web 说明](https://github.com/lzmzzw/zGIS/blob/v0.4.0/docs/web.md)。macOS 产物使用 ad-hoc 签名，仍未提供 Developer ID 签名和 Apple 公证。
