# zGIS 0.3.4

本版包含 [0.3.3](0.3.3.md) 的图层来源管理、SHP/ZIP 回写和数据库恢复与冲突同步功能，并修复阻止该版本发布的页面回归测试。

- 工作区图层首次保存测试按当前流程选择格式与路径，再验证文件绑定和后续保存。
- SHP 导出测试使用明确的导出入口，保留取消、失败、成功后编辑内容的验证。
- macOS 快捷键和文件字段编辑夹具补全来源坐标系与文件来源信息，符合恢复后直接回写的校验要求。
- SHP 文件菜单测试独立生成夹具，不再依赖其他测试的执行顺序或已有 `output` 文件。

提供 Windows x64 NSIS 安装包、macOS ARM64 DMG、app 压缩包及统一 SHA256SUMS.txt。macOS 使用 ad-hoc 签名，未使用 Developer ID 签名和 Apple 公证。
