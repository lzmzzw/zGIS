# zGIS 0.3.9

修复 Windows 应用内覆盖安装在 PowerShell 7 启动环境下失败的问题。安装助手使用系统 PowerShell 的默认模块路径，避免找不到安装包校验命令；失败记录补充阶段码和错误标识，便于定位。

延续 0.3.8 的应用内更新功能：下载正式发行安装包并校验 SHA-256，保存工作区恢复副本后退出、覆盖当前安装目录并自动重启。编辑中的会话可取消安装，存在其他 zGIS 实例时停止安装。

提供 Windows x64 NSIS 安装包、macOS ARM64 DMG、app 压缩包及 SHA256SUMS.txt。macOS 可下载并打开校验后的 DMG，应用替换仍需手工完成；未进行 macOS 自动覆盖安装验收。
