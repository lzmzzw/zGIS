# 图层显示

图层样式只改变本地显示，随桌面工作区恢复保存；不修改要素属性，不向 GeoJSON 或 SHP 写入样式扩展。Web 使用相同显示模型，下载仍只输出数据。MCP 不提供样式修改操作。

## 检查器与图例

点击图层符号打开右侧检查器的样式页，字段概览与样式在同一检查器内切换。颜色、透明度、线宽、着色和标注修改即时预览；「应用样式」保存到图层显示配置，取消或关闭放弃草稿。外部显示配置变化会重置旧草稿，字段失效时提示重新选择。只读图层也可调整显示。

图层图例可折叠，列出颜色、类别或分级区间，以及当前已加载要素的数量；null、缺失与其他值分别计数。数量不随地图范围或选择改变，不代表数据库全表数量。

## 字段概览

概览只读取当前图层全部已加载要素，不修改属性，不随地图视口或选中范围变化。有效（非空）、null 与缺失分别统计，显示类型分布；纯安全数值字段提供最小值、最大值、均值、中位数与最多 10 段直方图，其他字段展示频次最高的 8 个标量值。数字文本不转换成数字，对象和数组只统计类型。均值与中位数使用浮点近似，不用于精确财务计算；显示舍入不修改原值。

概览最多处理 10000 个要素、512 个字段和 100000 次字段访问；字段名最多 512 个字符，单个文本最多 4096 个字符，文本累计预算为 4 MiB（按 UTF-16 估算）。超过预算明确提示，不返回部分统计。纯安全数值字段可通过「按此字段分级着色」进入样式草稿，仍需应用后保存。

## 分级着色

数值字段支持等间隔、分位数和手动断点，最多 32 级；重复断点合并，常量字段可成为单级。手动断点必须是严格递增的安全数值。区间使用左开右闭规则，首尾无界，恰好落在断点上的值归入较低一级。颜色和断点保存后保持稳定，数据变化不会自动重算。

数字文本、布尔值、对象、数组及不安全数值归入「其他」，null 与缺失单独着色；数值只接受有限且绝对值不超过 `Number.MAX_SAFE_INTEGER` 的值。分类与分级不能同时启用，切换着色方式会在草稿中替换原方式。旧工作区无分级配置时保持既有显示，非法分级配置恢复时忽略。

## 分类着色

默认沿用单色。选择「字段唯一值」后，按当前要素顺序收集前 32 个字符串、有限数值或布尔唯一值，每类可修改颜色；数字 `1` 与字符串 `"1"` 分开。额外值及对象、数组使用「其他」，null 与字段缺失各有独立颜色。分类表保存后保持稳定，新增值不会挤占原有类别；需要按新数据重新生成时使用「按当前数据重建分类」，该操作重置分类颜色。

透明度和线宽继续对整层生效，选中要素保留既有高亮。分类不修改 OpenLayers 几何属性，业务字段名为 `geometry` 时仍可用于分类。

字段重命名、删除或外部数据刷新后，原分类字段可能不再存在；配置保留，当前要素采用缺失颜色，面板提示重新选择字段或切回单色。撤销字段操作恢复原字段后，原分类重新生效。旧工作区没有分类配置时保持单色，非法分类配置在恢复时回退为单色。

实现由 `layerDisplay.ts` 负责分类和值校验，`mapDisplayStyle.ts` 根据文档属性生成有界样式缓存，`LayerDisplayControls.tsx` 提供桌面与 Web 共用控件；显示配置和数据属性分别保存。

## 字段标注

默认关闭。启用后选择一个字段，可设置字号（8–32 px）、文字颜色、描边颜色和宽度（0–6 px，0 表示无描边）。字符串、有限数值和布尔值可显示；null、字段缺失、对象与数组不显示。字段重命名或删除后保留原标注配置、暂不显示文字，重新选字段或撤销字段操作后恢复。

每层按当前要素顺序最多取前 1000 条有几何和有效文字的要素；缩放不会让预算外要素进入标注集合。每条最多 80 个 Unicode 字符，超出以省略号结尾，换行和制表符替换为空格。多部件要素只在第一个部件标注一次，避免单条要素产生无限量文字。

OpenLayers 在启用标注的图层之间自动避让文字，拥挤时可能少于预算数量；点、线、面仍然绘制，不因文字被避让而消失。标注使用有界缓存，随属性与显示配置更新。文字只用于显示，完整属性值仍保留在数据中；旧恢复副本没有配置时保持关闭，非法配置恢复时忽略。
