# 图层显示

图层样式只改变本地显示，随桌面工作区恢复保存；不修改要素属性，不向 GeoJSON 或 SHP 写入样式扩展。Web 使用相同显示模型，下载仍只输出数据。MCP 不提供样式修改操作。

## 检查器与图例

点击图层符号直接打开右侧图层样式检查器，不设页签。字段数据统一在属性表查看。符号、着色和标注修改即时预览；「应用样式」保存到图层显示配置，取消或关闭放弃草稿。外部显示配置变化会重置旧草稿，字段失效时提示重新选择。只读图层也可调整显示。

图例只在右侧「图层样式」页展示，可折叠，列出符号、类别或分级区间，不显示要素数量。null、缺失与其他值保留各自图例项。左侧图层列表不提供图例展开入口。

## 几何符号

样式控件按图层实际几何显示，Multi 几何使用对应的点、线、面设置；混合几何提供所包含类型的设置。

- 点：填充颜色、边框颜色、点直径和边框宽度。
- 线：线条颜色、线宽，以及实线、虚线或点线。
- 面：填充颜色、填充不透明度、边框颜色、边框宽度及线型。填充不透明度为 0 时仅保留边框。

图层不透明度作用于整层；面的填充不透明度单独控制内部填充，不影响边框。混合几何中的线条与边框共用宽度和线型，颜色分别配置。分类或分级着色作用于点、面的填充及线条颜色，边框颜色保持独立；启用后对应的单色控件禁用，改用分类或分级颜色表调整。

显示配置随工作区保存，旧快照缺少新增配置时沿用既有颜色、线宽和填充强度，点默认直径 10px、线型默认实线；非法配置恢复时使用安全默认值。显示设置不进入数据导出。

## 分级着色

数值字段支持等间隔、分位数和手动断点，最多 32 级；重复断点合并，常量字段可成为单级。手动断点必须是严格递增的安全数值。区间使用左开右闭规则，首尾无界，恰好落在断点上的值归入较低一级。颜色和断点保存后保持稳定，数据变化不会自动重算。

数字文本、布尔值、对象、数组及不安全数值归入「其他」，null 与缺失单独着色；数值只接受有限且绝对值不超过 `Number.MAX_SAFE_INTEGER` 的值。分类与分级不能同时启用，切换着色方式会在草稿中替换原方式。旧工作区无分级配置时保持既有显示，非法分级配置恢复时忽略。

## 分类着色

默认沿用单色。选择「字段唯一值」后，按当前要素顺序收集前 32 个字符串、有限数值或布尔唯一值，每类可修改颜色；数字 `1` 与字符串 `"1"` 分开。额外值及对象、数组使用「其他」，null 与字段缺失各有独立颜色。分类与分级颜色编辑器展示与图例相同的几何符号，叠加当前草稿的边框、线型、填充及图层不透明度；点击符号或用键盘聚焦可修改该类别的填充或线条颜色。分类表保存后保持稳定，新增值不会挤占原有类别；需要按新数据重新生成时使用「按当前数据重建分类」，该操作重置分类颜色。

图层不透明度及几何符号的宽度、尺寸和线型继续生效，选中要素保留既有高亮。分类不修改 OpenLayers 几何属性，业务字段名为 `geometry` 时仍可用于分类。

字段重命名、删除或外部数据刷新后，原分类字段可能不再存在；配置保留，当前要素采用缺失颜色，面板提示重新选择字段或切回单色。撤销字段操作恢复原字段后，原分类重新生效。旧工作区没有分类配置时保持单色，非法分类配置在恢复时回退为单色。

实现由 `geometryStyle.ts` 识别几何类型，`layerDisplay.ts` 负责分类和值校验，`mapDisplayStyle.ts` 根据文档属性生成有界样式缓存，`GeometryStyleControls.tsx` 与 `LayerDisplayControls.tsx` 提供桌面与 Web 共用控件；显示配置和数据属性分别保存。

## 字段标注

默认关闭。启用后选择一个字段，可设置字号（8–32 px）、文字颜色、描边颜色和宽度（0–6 px，0 表示无描边）。字符串、有限数值和布尔值可显示；null、字段缺失、对象与数组不显示。字段重命名或删除后保留原标注配置、暂不显示文字，重新选字段或撤销字段操作后恢复。

每层按当前要素顺序最多取前 1000 条有几何和有效文字的要素；缩放不会让预算外要素进入标注集合。每条最多 80 个 Unicode 字符，超出以省略号结尾，换行和制表符替换为空格。多部件要素只在第一个部件标注一次，避免单条要素产生无限量文字。

OpenLayers 在启用标注的图层之间自动避让文字，拥挤时可能少于预算数量；点、线、面仍然绘制，不因文字被避让而消失。标注使用有界缓存，随属性与显示配置更新。文字只用于显示，完整属性值仍保留在数据中；旧恢复副本没有配置时保持关闭，非法配置恢复时忽略。
