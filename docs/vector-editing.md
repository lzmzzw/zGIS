# 矢量创建与编辑

zGIS 按图层开启编辑模式。源文件保存和工作区恢复各有用途：保存把当前要素写到明确选择的文件或数据库；恢复副本用于继续上次工作，不能代替源文件保存。

编辑工具栏按用途分组，并使用分割线区分浏览、几何编辑、新增要素、记录操作、历史辅助和保存。保存操作显示为“保存”和“保存并退出”；图层标题与编辑提示会区分“仅工作区副本”“源文件未保存”和“源文件已保存”。自动恢复成功只代表工作区草稿已保留，不代表源文件已经写入。

## 新建与绘制

从「文件 → 新建」填写名称，选择点、线、面，可用逗号分隔初始字段。创建后自动进入对应绘制工具。新建图层固定几何类型，工作坐标为 WGS84，首次保存为 GeoJSON；其他格式由导出入口选择。初始字段使用文本空值，可在属性表中编辑。

- 点：单击地图新增，可连续添加。
- 线、面：单击增加节点，Enter、双击或「完成绘制」完成一条要素。完成后继续绘制下一条。
- Backspace 或「撤回上一节点」撤回节点；Esc 或「取消绘制」取消当前草稿，保留此前完成的要素。

绘制草稿未结束时不能切换工具或修改属性。先完成或取消草稿，再进行下一步。

## 编辑已有要素

先激活图层，点击地图工具栏「编辑」或属性表「编辑属性」。点、线、面、Multi 几何与面洞都在同一编辑模式中操作。

- **移动要素**：直接拖动当前图层的要素整体移动；拖动空白处仍可平移地图。
- **编辑顶点**：单击要素选择，显示全部顶点；拖动顶点改变形状，拖动边添加顶点，Alt+单击顶点删除。线至少保留两个节点，面环至少保留三个不同节点。
- **修改属性**：属性表双击单元格；Enter/应用提交，Esc/取消放弃。长文本或 JSON 使用单独窗口。「更多」可修改完整 JSON 属性或 WKT 几何。
- 选中要素后，编辑提示区直接提供“编辑 JSON 属性”和“编辑 WKT 几何”入口，右键菜单仍可使用。
- **记录与字段**：属性表工具栏仅保留属性编辑图标和显示控制，记录删除在编辑模式的行右键菜单中；新增要素通过地图绘制，保存使用地图编辑工具或 Ctrl+S。字段列头菜单可新增、重命名、删除字段，作用于全部记录，支持撤销重做。数据库新增字段默认 varchar(255)，保存时同步数据表；几何列、主键和生成字段受保护。
- **删除与历史**：Delete 或工具按钮打开删除确认。撤销/重做支持 Ctrl+Z、Ctrl+Shift+Z、Ctrl+Y；绘制中的 Ctrl+Z 撤回节点。

捕捉作用于当前图层顶点和边，使用固定像素容差，缩放后仍容易命中。已存在顶点移动保留高程，XYZ 边上插点按端点插值高程；已有二维图层新增要素保持 XY，空新建或含高程图层新增要素默认 Z=0。地图操作失败会恢复操作前的图形。

编辑对象始终是当前图层。编辑期间切换图层、打开数据或移除当前图层会提示先保存并退出；设置页面往返保留模式。空间分析结果待编辑结束后再加入，避免后台结果改变编辑对象。

## 保存、退出与恢复

「保存」或 Ctrl+S 保存并继续编辑；「保存并退出」保存成功后退出。无修改时也可保存后退出。文件对话框取消、格式校验失败、来源外部修改冲突或数据库提交失败均保留编辑模式和内容。保存成功后提示源文件状态；恢复副本状态不会替代源文件保存。

GeoJSON/CSV 保存遵守既有来源指纹保护。SHP「另存为」在所选文件夹输出新 SHP 文件组，不打包 ZIP、不覆盖原文件组；导出仍可选择 SHP ZIP；数据库图层使用相同保存按钮，后台执行事务提交。普通导出不结束编辑模式，也不清除未保存标记。

任何图层处于编辑模式时，关闭窗口或从文件菜单退出都会询问。「返回编辑」继续操作；「退出并保留工作区」写入工作副本和编辑会话，下次自动恢复。未完成的绘制固定节点、单元格草稿、JSON/WKT 文本、当前工具、选择、捕捉和撤销历史均保留，未完成文本不要求先通过格式校验。关闭时恢复文件或配置保存失败会阻止退出。

恢复历史最多保留 30 步，受要素数量和恢复文件体积预算约束，超限时先缩短历史，优先保存当前要素与草稿。

桌面先写本地恢复日志，再串行写入原子恢复文件；成功后清除对应日志。两份副本携带递增版本，启动时使用较新记录，避免强退后 WebView2 的旧日志覆盖已保存内容。进程被强制结束时从最近持久化记录恢复。未松开的拖动尚未成为完整操作，恢复此前已完成的图形。磁盘故障、存储配额或过大数据导致恢复写入失败时会提示，不能保证未成功持久化的操作可恢复。

恢复仍脱离原文件句柄和数据库身份，统一为需要另存的本地 GeoJSON 副本，不保存连接凭据或提交基线。损坏的恢复文件报错并保留；旧数组与 v2 工作区继续可读，新格式为 v3。

## QGIS 参考与本次取舍

参考 [QGIS 3.44 矢量编辑说明](https://docs.qgis.org/3.44/en/docs/user_manual/working_with_vector/editing_geometry_attributes.html) 的按图层编辑、局部编辑缓冲区、顶点工具、移动要素和保存编辑流程。QGIS 允许保存或丢弃后停止编辑；zGIS 按本项目要求只在成功保存后退出编辑模式。

原实现已有绘制、Modify、捕捉和撤销，但选择/图层变化会重建交互，选择高亮使用静态副本，拖动反馈不连续；缺少整要素移动，顶点只在指针附近出现。编辑模式还会随切层清除，恢复文件只包含已应用要素。当前改为稳定选择集合、共享真实几何高亮、全顶点显示与独立移动工具，并将编辑会话纳入恢复记录。

本次覆盖日常创建、移动、顶点与属性编辑。旋转、缩放、拆分、多部件增删、洞增删、拓扑联动、自动追踪及 CAD 约束尚未实现；现有多部件和洞可通过顶点/WKT 修改。几何仍做结构校验，不承诺完整拓扑修复或与 QGIS 全部高级数字化能力等价。

## 验证入口

前端 `pnpm test`、`pnpm build`；页面交互 `pnpm exec playwright test tests/vector-editing.spec.ts tests/map-edit-session.spec.ts tests/workspace.spec.ts`；后端按 README 执行 Rust 测试。地图交互测试使用生成数据与真实 OpenLayers 画布，原生保存与跨进程恢复需要独立 WebView2 实例验证。

原生隔离 smoke 使用独立应用标识，不替换安装版或读取用户恢复文件。先生成 `output/vector-smoke.config.json`，内容为 `{"identifier":"com.personal.zgis.vector-smoke"}`，载入 MSVC 后执行 `pnpm tauri build --no-bundle --config output/vector-smoke.config.json`，再执行 `node scripts/vector-edit-native-smoke.mjs`。脚本核对测试标识，生成数据、调用原生保存窗口、强制结束自身进程两次并重启，验证绘制节点和属性草稿恢复；报告位于 `output/vector-native/report.json`。测试产物独立于正式 NSIS 包；安装验证仍遵守 README 的包外安装流程。
