# 有界分析与导入

`analysis_runtime` 提供进程级计算槽、任务 ID、协作取消及期限控制。槽位直到阻塞计算真正结束才释放；不能通过停止等待或重启 MCP 提前释放。默认同时最多 2 个计算任务，期限为 120 秒。桌面入口 `gis_run_analysis` 接受可选 `jobId`，`gis_cancel_analysis` 只取消桌面所属任务；未传 ID 的旧调用保持兼容。

算法与加载循环通过 `checkpoint` 检查取消/期限。单次第三方几何库调用不能被抢占，实际退出取决于下一个检查点；这不是硬实时超时或内存隔离。发生副作用前使用 `commit_checkpoint` 原子确定取消/提交的胜方，已提交的结果不会再被迟到取消改成失败响应。

外部文件仍限制 100 MiB、100000 要素；加载增加单要素 1000000、累计 2000000 个坐标位置预算（XYZ 算一个位置），分析继续遵循自己的更小规模约束。GeoJSON 使用带缓冲的读取器，避免完整原始文件字节与解析树同时保留；顶层 type 先于 features 的集合逐要素检查预算，其他合法键序使用兼容路径。单要素仍先解析后检查，不能把这些限额解释为严格的峰值 RSS 上限。CSV/SHP 逐记录检查预算，读取与转换循环检查取消。

恢复文件保存先校验长度，通过 `IgnoredAny` 校验 JSON，避免为校验再次构造完整树。磁盘写入在 blocking 线程执行，串行锁随实际写入任务持有；仍保留临时文件、落盘同步、校验和原子替换。

验证入口：`cargo test --manifest-path src-tauri/Cargo.toml --lib --locked`。运行时回归覆盖共享容量、任务所有权、早取消、期限、panic 后上下文恢复及取消/提交竞态；文件回归覆盖坐标预算、非标准键序、高精度属性和既有格式语义。
