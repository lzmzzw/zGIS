# zGIS 界面设计约定

本次改版依据用户多轮选择，参考 zTerm 的紧凑结构、zNote 的克制视觉及 zForge 的工作台风格。本文保存目标设计；实际能力与边界仍以 README 为准。

## 视觉与布局

- 中性灰配克制蓝色，适中密度；工具约 32px、图层行 36px。
- 深浅主题由设置切换。浅色采用较深灰 header、浅灰侧栏、白色表格内容区，分区清晰。
- 自定义单行 header 容纳文件、数据、视图菜单与窗口控制，不显示重复品牌标题；空白区域拖动窗口，双击最大化或还原。编辑工具浮在地图左上角，竖排放置。
- 图层默认显示，宽约 200px；检查器按需显示，宽约 236px；属性表默认关闭，可调整高度。
- 空工作区保持地图可用，左侧默认空白，空白处右键添加文件、PostGIS 或分组，不设中央欢迎卡片。
- 底图按钮位于地图右下角，展开单选服务卡片与独立显示开关；主题、注记与 tk 在后台设置页集中管理，底图区不提供重复设置入口。

## 查看与编辑

- 单击选择，双击定位。图层为单行；样式与来源详情放在检查器。
- 检查器提供图层、要素两个视图；要素属性先进入编辑，再应用或取消。
- JSON/WKT 独立窗口，左侧编辑、右侧摘要；遵守现有无损属性解析及二维与 XYZ 高程保留规则（M/ZM 不支持）。
- 字段操作位于列头菜单；添加字段作用于当前本地图层全部要素，不提供数据库 schema 设计。
- 绘制与顶点工具位于地图左上竖排工具栏，显示工具名称；完成、取消采用图标，节点数量放状态栏。
- 捕捉只切换当前图层顶点与边。选中几何为蓝色边界和淡蓝填充，仅顶点编辑显示节点。
- 只读图层显示锁标记，就地禁用编辑并说明来源限制；查看、样式、定位、导出仍可用。
- 地图提供缩放、图层范围与比例尺；坐标与 CRS 放状态栏。

## 数据与窗口

- 保存、另存、导出归文件菜单。导入自动识别，需要时才配置。
- CSV 左侧配置、右侧预览；导入错误在原窗口对应输入附近显示，保留配置供修正。
- 导出左侧配置、右侧摘要，格式决定设置。
- PostGIS 数据表选择在添加图层弹窗；连接窗口为基础字段与折叠高级设置，折叠时仍显示 TLS 状态。
- 双击数据库表打开加载设置；明确提交展示目标及增删改数量，冲突留在原窗口并提供可展开详情。
- 设置采用独立后台页，左分类、右内容，包含外观、地图、空间分析 MCP 和关于；唯一入口为 header「设置」按钮。返回地图保留工作区，Esc 可返回。主题即时生效并持久化；天地图支持类型、注记及会话内 tk；MCP 配置与授权遵守原有契约。
- 自动加载恢复副本并通知；数据库恢复为本地副本，禁止直接提交回来源。
- 退出逐图层选择保存、保留或放弃，显示摘要；处理失败则保留工作区。

## 实现边界

上述布局与流程已落实。恢复副本校验后自动加载，统一脱离原文件句柄与数据库身份；无效恢复文件保留并报错。退出处理按图层顺序执行，取消或失败保留工作区，已成功保存或提交的图层保留完成状态。实际文件格式、几何与数据库支持范围见 README。

- 统一图层树支持嵌套分组，拖动排序或移入分组；树上方图层在地图上方。分组显隐继承到子层，折叠只影响列表。恢复副本保留分组、顺序与显隐，兼容旧恢复数组。

- 所有下拉框保留原生 select 语义；支持 `appearance: base-select` 的 Chromium/WebView2 使用统一主题选项浮层、选中勾选与视口边界定位，旧内核回退为主题化原生下拉框。Escape 优先关闭展开的下拉菜单，再关闭外层页面。
- 输入框、禁用状态、菜单浮层与 MCP/助手面板共用主题 token；助手终端切换主题时原地更新配色，不重建会话。

- 隐藏底图保留选中服务；OSM 默认可用，填写天地图 tk 后展示矢量和影像服务。底图 z-index 为 0、注记为 1，业务图层在上。地图右下角不显示来源浮标，来源说明位于底图面板；卡片配图为服务类型示意。
