# zGIS 界面设计约定

本次改版依据用户多轮选择，参考 zTerm 的紧凑结构、zNote 的克制视觉及 zForge 的工作台风格。本文保存目标设计；实际能力与边界仍以 README 为准。

## 视觉与布局

- 中性灰配克制蓝色，适中密度；工具约 32px、图层行 36px。
- 深浅主题由设置切换。浅色采用较深灰 header、浅灰侧栏、白色表格内容区，分区清晰。
- 单行 header 同时容纳文件、数据、视图菜单与图标工具，不保留独立工具栏或活动栏。
- 图层默认显示，宽约 200px；检查器按需显示，宽约 236px；属性表默认关闭，可调整高度。
- 空工作区保持地图可用，打开文件与数据源入口位于左侧，不设中央欢迎卡片。
- 底图选择位于图层区底部，设置快捷入口打开「设置 → 地图」。

## 查看与编辑

- 单击选择，双击定位。图层为单行；样式与来源详情放在检查器。
- 检查器提供图层、要素两个视图；要素属性先进入编辑，再应用或取消。
- JSON/WKT 独立窗口，左侧编辑、右侧摘要；遵守现有无损属性解析及二维几何限制。
- 字段操作位于列头菜单；添加字段作用于当前本地图层全部要素，不提供数据库 schema 设计。
- 绘制与顶点工具位于 header，显示工具名称；完成、取消采用图标，节点数量放状态栏。
- 捕捉只切换当前图层顶点与边。选中几何为蓝色边界和淡蓝填充，仅顶点编辑显示节点。
- 只读图层显示锁标记，就地禁用编辑并说明来源限制；查看、样式、定位、导出仍可用。
- 地图提供缩放、图层范围与比例尺；坐标与 CRS 放状态栏。

## 数据与窗口

- 保存、另存、导出归文件菜单。导入自动识别，需要时才配置。
- CSV 左侧配置、右侧预览；导入错误在原窗口对应输入附近显示，保留配置供修正。
- 导出左侧配置、右侧摘要，格式决定设置。
- PostGIS 数据源在左侧面板；连接窗口为基础字段与折叠高级设置，折叠时仍显示 TLS 状态。
- 双击数据库表打开加载设置；明确提交展示目标及增删改数量，冲突留在原窗口并提供可展开详情。
- 设置左分类、右内容，即时生效；天地图支持类型、注记及会话内 tk。
- 自动加载恢复副本并通知；数据库恢复为本地副本，禁止直接提交回来源。
- 退出逐图层选择保存、保留或放弃，显示摘要；处理失败则保留工作区。

## 分批落实

首批落实主界面、双主题、检查器与属性编辑、JSON/WKT 窗口、字段入口、捕捉和绘制控制。导入/导出、PostGIS、自动恢复与逐图层退出流程继续依本约定改版；未落实部分不能作为当前功能对外宣称。
