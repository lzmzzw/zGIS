# zGIS 界面设计约定

空间分析工具箱位于主界面右侧，由 header 左侧「工具」切换，位于「设置」左侧，与文件、数据、设置采用一致的纯文字样式，与 Codex Agent 侧栏互斥显示。两者都停靠在工作区右侧，使用同一标题栏、面板表面和分隔边界；地图与属性表随侧栏缩放，不被侧栏覆盖。默认宽 368px，可拖动左边缘调整，或聚焦分隔条后按左右方向键调整 20px、Home/End 到最小/最大宽度。宽度范围 320–720px，工具箱与 Agent 分别记忆；窄桌面窗口按可用空间限制显示宽度，为地图保留至少 360px，放大窗口后恢复所选宽度。工具树列表固定高 200px，搜索与工具树外框使用低对比度边界。类别默认全部折叠，点击类别展开工具；初始不选工具，点击工具选中、再次点击取消选中。未选中时隐藏参数、运行区与使用说明；重新选中恢复该工具本次会话参数。搜索没有占位文案，输入时自动展开匹配类别，清空后恢复手动展开状态。工具区、参数区、运行区与底部使用说明通过表面、留白和细边界区分；输入与输出分区，字段标签与控件同行，图层选项不显示要素统计。不显示选择工具标题、工具数量、分类下拉框、工具用途短句、输出提示、就绪提示、收藏、最近或运行记录；错误保留输入，运行期间锁定重复操作。编辑中的图层先保存退出，分析结果独立加入图层树；完整语义见 [空间分析工具箱](processing-toolbox.md)。

本次改版依据用户多轮选择，参考 zTerm 的紧凑结构、zNote 的克制视觉及 zForge 的工作台风格。本文保存目标设计；实际能力与边界仍以 README 为准。

## 视觉与布局

- 中性灰配克制蓝色，适中密度；工具约 32px、图层行 36px。
- 深浅主题由设置切换。浅色采用较深灰 header、浅灰侧栏、白色表格内容区，分区清晰。
- 字体、字号、字重与图标尺寸统一使用 `src/styles.css` 的公共变量。界面沿用 Segoe UI、Microsoft YaHei；正文 13px，辅助文字 12px，元信息 11px。弹窗标题 15px，设置分类标题 17px、页面标题 19px；品牌与统计数字保留独立字号。代码、坐标和助手终端共用 Consolas 等宽字体。
- Lucide 图标由 CSS 按场景统一尺寸，组件不再逐个指定 `size`：普通操作 16px，地图编辑工具 18px，搜索、字段添加和树展开等紧凑标记 14px，底图入口 20px、选中徽标 12px。通用控件沿用 32px 高、4px 圆角；面板尺寸、位置和主题色保持现状。
- 界面文案只保留操作所需的信息；来源限制、字段类型、读取上限、授权边界与错误原因必须保留。辅助说明避免重复标题或展开实现细节。
- 自定义单行 header 容纳文件、数据、设置入口与窗口控制，不显示重复品牌标题；空白区域拖动窗口，双击最大化或还原。编辑工具浮在地图左上角，竖排放置。
- 图层默认显示，默认宽 260px，右边缘可拖动调整（200–480px，并为地图保留 360px）；分隔条支持左右方向键、Home/End，宽度本机记忆，窗口变窄时临时限制显示宽度；取消右侧检查器，地图使用剩余宽度；属性表默认折叠并保留标题行，使用标题行右上角按钮展开或收起；展开后可调整高度；最大化/还原位于右侧折叠按钮旁，使用外扩/内收图标、提示文字和选中状态区分。
- 空工作区保持地图可用，左侧默认空白，空白处右键添加文件、PostGIS 或分组，不设中央欢迎卡片。
- 底图按钮位于地图右下角，展开单选服务卡片与整体显示开关；只列出设置中允许显示的服务，底图区不提供重复设置入口。

## 查看与编辑

- 图层树使用固定的折叠箭头、复选框、符号与名称列，每级缩进 20px，叶子行保留箭头占位。同级分组和图层的复选框、符号及名称对齐；父组隐藏时淡化后代名称，保留子层本地勾选状态。
- 面、线、点（含 Multi）分别用正方形、线条、圆点；混合类型斜分符号，空几何虚线框。点击符号是唯一样式编辑入口，独立「图层样式」弹窗以草稿管理颜色、透明度和线宽，应用生效，取消或 Esc 放弃。只读来源仍能调整显示样式。
- 图层名称单击激活，双击定位；右键「图层属性…」仅管理来源与属性字段，不显示样式控件。右键「重命名图层…」只修改 displayName，保留来源 name 与保存/导出的默认文件名；恢复副本同时保存两者，兼容旧快照。重命名弹窗支持 Enter、Esc 和焦点返回。
- 要素属性统一在底部属性表：浏览模式单击选择、双击记录定位；开启「编辑属性」后双击单元格或 Enter 开始，Enter 应用，Tab 应用并移到下一字段，Shift+Tab 移到上一字段，Esc 取消。几何类型列只读。
- 单元格按原值类型校验，文本保留前导零，NULL 使用显式开关；原值为 NULL 或缺失时填写 JSON 值。高精度数值不静默转成近似数值，需通过 JSON 属性编辑按无损规则处理。长文本与对象/数组用独立窗口编辑。失焦不提交，错误保留输入并就近提示，单元格确认加入撤销/重做历史。
- 草稿期间禁用切换对象、搜索及分页；设置往返保留草稿，应用退出确认后保留草稿以便下次继续。空间分析结果在当前图层编辑模式和弹窗结束后加入，避免异步切换编辑目标。
- 属性表「更多」提供选中要素的 JSON/WKT 独立窗口，左侧编辑、右侧摘要；遵守现有无损属性解析及二维与 XYZ 高程保留规则（M/ZM 不支持）。
- 字段操作位于列头菜单；添加字段作用于当前本地图层全部要素，不提供数据库 schema 设计。
- 绘制与顶点工具位于地图左上竖排工具栏，显示工具名称；完成、取消采用图标，节点数量放在工具旁，地图上方给出当前图层与简短操作提示。
- 捕捉只切换当前图层顶点与边。选中几何通过独立顶层高亮显示蓝色完整边界和淡蓝填充，避免相邻要素覆盖共享边；仅顶点编辑显示节点。地图选中时展开属性表、清除搜索条件并跳转到对应分页，将高亮记录居中于固定表头下方的可见记录区域，首末记录按真实滚动边界定位，不增加首尾占位留白；属性表展开、分页及尺寸变化时重新定位，保持全部记录可浏览及横向滚动位置。
- 只读图层显示锁标记，就地禁用编辑并说明来源限制；查看、样式、定位、导出仍可用。
- 地图提供缩放与图层范围，移除比例尺和 footer；经纬度显示在地图左下。
- 浏览状态显示手形、选择与编辑入口；手形只平移，不选中要素。编辑状态绑定当前图层，显示移动、顶点、绘制、删除、撤销重做与捕捉。「保存编辑」成功后继续编辑，「保存并退出编辑」成功后回到浏览；无修改时也可保存后退出，取消或失败保留状态。属性表使用同一模式。编辑期间禁止切换或移除当前图层，不因切层清除模式。SHP 另存新 ZIP，数据库保存仍需显式确认提交。详见 [矢量创建与编辑](vector-editing.md)。

## 右键菜单

- 顶栏、工具条和普通空白区域不显示浏览器默认菜单；输入框、文本编辑器和助手终端保留原生编辑菜单。错误、说明与代码文本提供复制入口。
- 图层树标题和空白处提供添加文件、PostGIS、新建分组。分组提供新建子分组、添加数据、显隐、展开折叠、重命名、排序、移到顶层和解散；解散须确认，保留子分组、图层和顺序。图层仅提供定位、属性表、显隐、属性、重命名、排序、移到顶层和移除；未保存修改沿用移除确认。
- 地图空白处提供复制经纬度、缩放图层、属性表、手形平移、选择与清除选择。命中当前可见图层的要素时增加定位、JSON/WKT 查看、复制属性或几何、编辑顶点与删除确认。绘制中只提供完成与取消等适用操作，不切换选中要素。
- 属性行菜单作用于右键记录；属性单元格增加复制原值和直接开始编辑。字段列头提供字段名、摘要复制与添加字段，PostGIS 禁用表结构修改。只读来源保留复制、查看与定位，禁用写操作；草稿期间不切换编辑对象。
- 自定义菜单共用主题、字号、间距、危险操作和禁用样式，不设重复标题栏。支持右键、菜单键与 Shift+F10，方向键、Home/End 跳过禁用项，Escape 关闭并返回焦点；点击外部、外部滚动或调整窗口大小关闭菜单，菜单互斥并限制在视口内。

## 数据与窗口

- 保存、另存、导出归文件菜单。导入自动识别，需要时才配置。
- CSV 左侧配置、右侧预览；导入错误在原窗口对应输入附近显示，保留配置供修正。
- 导出采用 520px 紧凑单栏：来源及要素信息置顶，标签和控件按行对齐，不重复展示输出摘要；格式决定设置。窄窗口堆叠标签与控件，长名称换行。保存位置仅保留一句提示，Shapefile 限制按需展开；CSV 保真限制、非默认 GeoJSON 坐标系兼容性与阻断错误直接可见。
- PostGIS 数据表选择在添加图层弹窗；连接窗口为基础字段与折叠高级设置，折叠时仍显示 TLS 状态。
- 双击数据库表打开加载设置；明确提交展示目标及增删改数量，冲突留在原窗口并提供可展开详情。
- 设置采用独立后台页，左分类、右内容，包含外观、地图、MCP 和关于；唯一入口为顶部左侧菜单区「设置」按钮。返回箭头和 Esc 返回原工作区。各分类只保留设置项、状态和必要错误，不重复说明标题及操作步骤。
- 地图设置仅显示底图服务列表，标题不显示服务总数，默认只提供 OpenStreetMap。全部服务均可添加、编辑、删除、排序，删除可撤销；添加与编辑共用独立弹窗，取消和 Esc 放弃输入并返回原按钮焦点。弹窗的「在地图中显示」决定前台是否列出和加载该服务；隐藏或删除当前项时按顺序回退到可显示服务，没有可用项时保持空底图。列表、顺序、逐项显示状态、当前选择和整体显隐在 Windows 加密保存；空列表与全部隐藏均可恢复，不重新加入预置服务。
- MCP 状态、服务操作、地址和令牌直接展示；连接配置与工具清单默认收起，各工具的完整说明展开该项后显示；不展示最近工具调用。配置与授权遵守原有契约。关于参考 zTerm，用四行卡片展示实际版本、GitHub 地址、GPL 3.0 和更新检查；链接通过系统浏览器打开，更新查询公开 Releases，发现新版本时提供发布页入口。
- 自动加载恢复副本并通知；数据库恢复为本地副本，禁止直接提交回来源。
- 所有图层操作自动保存，普通退出无弹窗，仅编辑模式未结束时确认；保存失败保留工作区。

## 实现边界

上述布局与流程以当前源码为准。恢复副本校验后自动加载，统一脱离原文件句柄与数据库身份；无效恢复文件保留并报错。退出刷新完整工作区及空分组；确认退出保留尚未应用的编辑草稿及工具、选择和撤销历史，返回编辑后可继续；异常退出恢复最近持久化记录。实际文件格式、几何与数据库支持范围见 README。

- 统一图层树支持嵌套分组，拖动排序或移入分组；树上方图层在地图上方。分组显隐继承到子层，折叠只影响列表。恢复副本保留分组、顺序与显隐，兼容旧恢复数组。

- 所有下拉框保留原生 select 语义；支持 `appearance: base-select` 的 Chromium/WebView2 使用统一主题选项浮层、选中勾选与视口边界定位，旧内核回退为主题化原生下拉框。Escape 优先关闭展开的下拉菜单，再关闭外层页面。
- 输入框、禁用状态、菜单浮层与 MCP/助手面板共用主题 token；助手终端切换主题时原地更新配色，不重建会话。

- 整体隐藏底图保留选中服务；默认 OSM 最高瓦片级别为 19。所有服务按通用 HTTP(S) XYZ 地址加载，天地图由用户自行添加；不再提供独立注记或 tk 控件。启动等待配置加载后请求瓦片，隐藏服务不发起请求。底图 z-index 为 0，业务图层在上；来源说明位于底图面板，卡片仅显示名称和地图预览；添加或保存服务时以武汉中心（114.3055, 30.5928）、默认 11 级生成 288×144 PNG 并缓存，服务最高级别更小时随之降低。无缓存的旧服务使用武汉中心瓦片，获取失败显示地图图标；预览失败不阻止保存，同地址保留旧图，地址变化清除旧图。获取期间禁用重复提交，取消和 Esc 放弃保存。旧配置移除无自定义地址的预置天地图，OSM 补齐地址，保留自定义服务及顺序。桌面 CSP 允许用户配置的 HTTP(S) 图片与连接，脚本、Worker 与样式策略不变。

- 分组支持多级子组。拖动组名行到另一组或子组行的中部可整组移入，目标组自动展开，所有后代及顺序、显隐状态保留；不能移入自身或后代。拖到行前后可排序，右键「移到顶层」可整组移出。

- 经纬度位于地图左下，绘制节点数在绘制工具旁，解析取消按钮在地图内显示；无 footer。操作结果通过无障碍状态播报，错误使用可见提示。
