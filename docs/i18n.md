# 中英双语

桌面版在「设置 → 外观 → 语言」选择中文或 English；Web 版在页面顶部选择，导入、下载等弹窗也提供语言入口。默认中文，选择保存在当前应用或站点的 `localStorage`，重新启动或刷新后沿用。浏览器禁用存储时，本次会话仍可切换。

切换立即更新菜单、设置、工具箱、导入导出、报告、提示、已显示的错误，以及按钮的无障碍名称和悬浮提示，不重建地图或清空图层、编辑草稿与展开状态。用户文件名、图层名、字段、属性值、查询内容、工具 ID、协议 schema 和终端输出保留原值。应用不翻译任意外部日志；已知解析、计算和原生服务诊断按语言显示。

桌面版同时同步原生文件对话框标题与 macOS 应用菜单。操作系统提供的文件选择器按钮、系统权限提示及浏览器离开确认由操作系统或浏览器决定语言，不由应用替换。

## 维护

共用语言状态与 `t`、`useLocale` 位于 `src/i18n/index.ts`；主界面、共享面板、Web 与服务诊断分别拥有 `app.ts`、`shared.ts`、`web.ts`、`errors.ts`。原生标题与菜单语言由 `src-tauri/src/locale.rs` 管理，前端通过 `set_locale` 同步。Web 不引入原生调用。

组件订阅 `useLocale`，在显示时调用 `t`。状态中的提示和错误保留规范来源文本，以便已经显示的信息也可双向切换。模板的编号占位符保留用户内容；命名的 `error`、`reason`、`detail` 等诊断占位符可递归翻译。`tool` 仅接受已登记的分析工具名称。React key、字段键、API 枚举与业务数据不能使用翻译结果。生成的可编辑名称属于数据，创建后保持用户可控。

新增文字同时提供英文翻译，两个版本的构建均运行 `pnpm i18n:check`。检查源码文字、可见 JSX、无障碍属性和翻译占位符；它不能替代动态页面检查。双语测试还扫描英文页面、全部 22 项工具表单及共享面板，并检查双向切换、已有错误、草稿、用户数据与语言记忆。

```powershell
pnpm i18n:check
pnpm test
pnpm build
pnpm exec playwright test tests/i18n.spec.ts tests/i18n-shared.spec.ts
pnpm build:web
pnpm test:web
```

Windows 原生验证使用独立的 `com.personal.zgis.processing-smoke` 标识构建，再运行 `node scripts/i18n-native-smoke.mjs <隔离程序路径> <本次验证目录>`。脚本拒绝生产标识，不覆盖安装版；macOS 菜单的实际运行验证需在 macOS 完成。
