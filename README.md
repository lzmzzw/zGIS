# zGIS

GitHub Actions 的检查、构建和发布流程见 [发布说明](docs/release.md)。

Windows 轻量地理数据查看与编辑器，使用 Tauri 2、React、OpenLayers 与 Rust。当前源码版本为 0.2.0，不包含 Python/GDAL 运行时。变更见 [0.2.0 说明](docs/releases/0.2.0.md)，模块职责与维护边界见 [代码结构](docs/architecture.md)。

## 功能

- GeoJSON、CSV（WKT 或 X/Y）、Shapefile 文件组与 ZIP 导入，多图层显隐、颜色、透明度、线宽和范围定位。
- 新建点、线、面图层；连续绘制、整要素移动、顶点修改与捕捉；二维普通和 Multi 几何、面洞；删除、撤销、重做。
- 属性表搜索与每页 100 条显示、属性编辑、JSON 属性编辑、WKT 几何编辑、添加字段。
- GeoJSON 与 CSV 保存/转换；SHP 工作副本可编辑，另存为在文件夹生成新的 SHP 文件组；导出可选择 SHP ZIP 或其他格式。
- PostGIS 连接、元数据发现、geometry / WKT 文本读取、有主键图层事务编辑、冲突检测和新表导入。
- 默认 OpenStreetMap；自定义 HTTP(S) XYZ 底图服务、逐服务显示管理与无底图模式。
- 自动保存工作区与编辑草稿、保存后退出编辑、应用关闭询问和异常退出恢复、文件外部修改冲突保护。
- 应用内空间分析工具箱，22 项矢量叠加、空间关系、几何转换和质量统计工具；分类树搜索与独立结果图层。操作与计算边界见 [工具箱说明](docs/processing-toolbox.md)。同一分析引擎也通过本机 MCP 提供给嵌入式 Codex CLI Agent，接入见 [空间分析说明](docs/spatial-mcp.md)。

## 运行与安装

0.2.0 安装包名称为 `zGIS_0.2.0_x64-setup.exe`，本地构建位于 `src-tauri/target/release/bundle/nsis/`；正式发布入口为 [GitHub Releases](https://github.com/lzmzzw/zGIS/releases)。当前用户安装默认目录为 `%LOCALAPPDATA%\zGIS`，启动文件为 `zgis.exe`；可从开始菜单启动。卸载使用 Windows 应用管理或安装目录的 `uninstall.exe`。

MCP 默认随应用启动，固定本机地址与令牌；外部文件直接按路径读取，访问权限由调用 Agent 判断。Codex 接入方法见 [空间分析说明](docs/spatial-mcp.md)。

依赖 Windows WebView2 Runtime。安装包使用 Tauri NSIS 引导方式，缺少 Runtime 时可能需要联网安装。当前构建未配置代码签名，不是已经签名的商业发布包。

## 操作

主界面左侧「工具」打开空间分析侧栏，选择工具、输入/目标图层与参数后运行；结果作为独立未保存图层加入地图，可继续分析或保存。拓扑检查和图层摘要直接显示报告。编辑中的图层须先保存退出；完整工具、属性规则和距离精度见 [空间分析工具箱](docs/processing-toolbox.md)。

界面采用无重复标题的自定义单行 header，空白区域可拖动窗口，双击可最大化或还原，右侧提供窗口控制按钮：文件菜单提供新建、打开、另存为与导出为，数据菜单提供 Mysql 数据源与 PostGIS 数据源，左侧图层默认展示，底部属性表通过自身标题行控制显示，右侧不再设置检查器。主界面仅在 header 保留一个「设置」入口，打开独立后台设置页：左侧分类，右侧集中管理外观、地图、MCP 与关于；「返回地图」或 Esc 返回原工作区，图层、选择和编辑状态保留。底图区域和 header 右侧不再提供重复设置或独立 MCP 入口。深浅主题在「设置 → 外观」即时切换并记住选择；底图按钮位于地图右下角，展开后单选已配置服务；「显示底图」开关保留当前选择，底图位于业务图层下方。「设置 → 地图」仅显示底图服务列表，支持添加、编辑、删除、排序和删除撤销。默认只提供 OpenStreetMap，同样可编辑或删除；天地图等服务由用户填写 HTTP(S) XYZ 地址添加（需包含 `{z}`、`{x}`、`{y}`）。添加与编辑弹窗的「在地图中显示」控制该服务是否出现在前台底图列表；隐藏当前服务时按顺序选择下一个可显示服务，全部隐藏或删除时不显示底图。底图切换卡片显示名称与武汉地图预览；添加或保存服务时刷新预览，获取失败仍可保存。预览缓存、服务列表、排序、逐项显示状态、当前选择及整体显隐跨重启保留，Windows 使用当前用户 DPAPI 加密配置。旧版内置天地图项移除，用户已有自定义服务保留。关于页展示实际版本、GitHub、GPL 3.0 和检查更新；检查公开 GitHub Releases，发现新版本后可在系统浏览器查看和下载安装包。完整改版约定见 [界面设计约定](docs/interface-design.md)。

可从资源管理器将 GeoJSON、CSV、SHP 或 ZIP 文件拖入窗口，自动按文件标记或默认 EPSG:4326 导入图层；SHP 自动收集同名配套文件。拖入解析失败会打开导入面板，修正字段、编码或坐标系后继续；打开面板或执行其他操作时请完成操作后再拖入。每批文件总大小最多 100 MB。

打开 GeoJSON 或 CSV；GeoJSON 可按文件 `crs` 标记识别或明确选择来源坐标系，无标记默认 4326；CSV 左侧配置列名、编码与 CRS，右侧显示前 5 行实际数据。预览在 Worker 中执行，导入时校验全部记录，错误留在原窗口；可明确切换 WKT 与 X/Y，支持 EPSG:4326 / EPSG:4490 / EPSG:3857，默认 EPSG:4326。打开单个 SHP 时桌面后端会收集同目录同名配套文件；必须具备 DBF、PRJ，中文编码优先按 CPG 解释。ZIP 内支持多组 SHP。

左侧图层栏默认展示。属性表默认折叠，仅保留属性表标题行，通过该行右上角按钮展开或收起；展开后可拖动上沿调整高度，或通过右侧折叠按钮旁的最大化/还原按钮浏览更多字段；两种状态使用外扩/内收图标及选中高亮区分。滚动首尾按真实记录边界显示，不添加空白占位。顶部左侧菜单区提供文件、数据和设置入口，右侧不再提供属性表或设置按钮。浏览模式单击选择要素，双击表格记录定位；开启「编辑属性」后，双击单元格或按 Enter 编辑，Enter 或「应用」提交，Tab 提交并移到下一字段，Shift+Tab 移到上一字段，Esc 或「取消」放弃草稿。数值、布尔值、文本与 NULL 分别处理；长文本和对象/数组在独立单元格窗口编辑，无效输入保留并提示。草稿未结束时禁止切换要素、图层、搜索及分页，进入设置仍保留草稿。底部「更多」提供选中要素的 JSON 属性与 WKT 几何编辑；「定位到选中要素」可独立调整地图视角。地图选择会打开属性表并跳到对应记录。左侧图层栏默认宽 260px，可拖动右边缘或聚焦分隔条后按左右方向键调整，Home/End 到最小/最大宽度；记住上次选择，并在窄窗口为地图保留空间。图层使用复选框切换显隐，分组和子组按固定列对齐、每级缩进 20px。面、线、点图层分别使用正方形、线条和圆点；混合类型使用斜分符号，空图层使用虚线框。点击符号是唯一样式入口，在独立弹窗设置颜色、透明度和线宽，「应用样式」确认，取消或 Esc 放弃草稿。图层名称单击激活、双击定位；右键「图层属性…」只查看来源、坐标系和属性字段，提供添加字段和打开属性表入口，不再提供样式编辑。右键「重命名图层…」仅修改显示名并保存到恢复副本，原始文件名、保存/导出的默认文件名保持不变；来源名称仍可在图层属性中查看。WKT 坐标始终为 WGS84 经纬度。矢量操作见 [矢量创建与编辑](docs/vector-editing.md)。文件或数据菜单的「新建矢量图层」选择点、线、面和初始字段，创建后进入编辑模式。已有图层先点击「编辑」，再选择要素、移动或编辑顶点。地图工具区区分「保存编辑」和「保存并退出编辑」；无修改也可保存后退出，取消或失败保留编辑模式。属性表编辑使用同一模式。编辑期间禁止切换或移除当前图层、打开其他数据；设置往返保留编辑状态。删除有确认步骤，可撤销。Shapefile 来源支持同样的属性、几何编辑与撤销重做；编辑发生在工作副本中，原文件组保持不变。

文件保存覆盖已打开的 GeoJSON/CSV 前检查指纹；来源发生外部修改时拒绝覆盖，可使用另存或导出。SHP 的保存入口进入导出。导出窗口左配置、右摘要，支持文件名与输出坐标；输出选择 GeoJSON、CSV WKT、CSV X/Y、SHP ZIP（桌面版）或 PostGIS 新表。X/Y 只接受 Point，不支持的几何就地提示并禁用导出；CSV 嵌套属性转为 JSON 文本。

“数据”菜单依次提供“Mysql 数据源”和“PostGIS 数据源”。两者使用三栏管理页：左侧新增、删除与连接数据源，中间搜索并切换全部表/仅含 geometry 的表，右侧默认预览 20 条，可切换 10 条。PostGIS 可选择 Schema（含空 Schema），MySQL 使用所连接数据库的表列表，不显示 Schema。连接配置跨重启保存，连接会话不保留；密码使用 Windows 当前用户 DPAPI 加密保存，连接设置中默认掩码，可点击显示/隐藏，删除源同时删除密码。源列表、恢复文件与日志不保存密码。

PostGIS 与 MySQL 的表从管理页添加到地图，geometry 或文本 WKT 为几何来源；管理页仅预览，不编辑记录。数据库图层和矢量文件使用同一套图层编辑、属性表编辑、新增/删除记录、保存及退出操作，保存不弹出数据库专用确认窗口。地图与 WKT 编辑只修改几何字段，属性表修改其他字段；属性表可新增空几何记录、删除记录及新增/删除/重命名字段。新增数据库字段默认 `varchar(255)`，重命名保留类型，字段操作支持撤销/重做，保存时同步来源。无主键图层只读，主键、几何列、自动生成列及受依赖约束的字段受到后端保护。

数据库保存使用主键定位、完整基线、事务和并发冲突检测，失败保留本地修改。PostGIS 字段结构与记录在同一事务提交。MySQL 仅支持 InnoDB 的记录提交；字段同步使用 MySQL 8+ 原子 ALTER，但 DDL 会隐式提交，结构成功而数据失败时明确报告并禁止重复提交，必须重新读取核实。数据库提交结果未确认或成功后重读失败也禁止重试。MySQL 最多加载 10000 条，支持 EPSG:4326，geometry SRID=0 需明确确认，属性修改不重写几何；几何写入与字段同步以 MySQL 8+ 为目标。MySQL 二进制属性、单属性超过 64 KiB 或总加载结果超过 16 MiB 拒绝加载。两引擎预览限制 128 列、1 MiB 与 15 秒，较大/复杂字段只显示摘要，不以摘要作为提交基线。真实数据库连接、DDL、TLS 与并发写回仍需指定测试环境验证。

### SHP 编辑与另存

桌面版导出 SHP ZIP，内含同名 SHP、SHX、DBF、PRJ、CPG，输出可选 EPSG:4326（默认）、EPSG:4490 或 EPSG:3857，属性编码为 UTF-8。目标 ZIP 必须不存在，已有文件拒绝覆盖。不覆盖原 SHP 文件组，不保留原 DBF schema、编码；三种坐标系以外的原投影保真写回的工作仍应使用专业 GIS 软件。

单个输出图层必须属于同一几何类别：Point、MultiPoint、线（含 MultiLineString）或面（含 MultiPolygon）。面洞和多部件保留；混合类别、空几何及 Z/M 拒绝输出。字段名为 1–10 个 ASCII 字母、数字或下划线，首字符不能为数字，不允许大小写重名。文本最多 254 个 UTF-8 字节，不接受空字符串或首尾空格，避免 DBF 填充及读取去空格造成数据变化；布尔值和安全数值可以输出，数值最多 15 位有效数字和 8 位小数且须保持往返精度。缺失值、NULL、对象、数组及不满足限制的字段明确报错，不静默截断、填零或改名。完全没有属性的图层会增加 ZG_ROW 行号字段，以便生成可互操作的 DBF。

普通导出成功不会清除工作副本的未保存标记；编辑状态的保存另存成功后清除标记，是否退出由所选保存入口决定，取消或失败保留编辑。图层操作自动保存到工作区副本，源文件仍需显式另存；再次打开导出的 ZIP 可继续编辑。UTF-8 中文跨软件兼容性应以实际目标软件验收为准。

## 当前边界

启动时自动校验并加载恢复副本，所有来源恢复为独立本地 GeoJSON，不保留文件句柄、数据库身份或提交基线；图层标注恢复来源。无效恢复文件报错并保留原文件。图层内容、样式、显隐、顺序和嵌套分组（含空组）自动保存，浏览状态正常退出先刷新完整工作区，不弹窗。只要图层处于编辑模式就询问退出；「返回编辑」继续操作，「退出并保留工作区」保存工作副本、编辑模式与尚未完成的绘制/属性/JSON/WKT 草稿，下次启动继续编辑。恢复副本不等于保存源文件。固定绘制节点与已应用修改会持续持久化，强行结束进程后也按最近成功保存的恢复记录继续；尚未松开的拖动按最后一次完成的操作恢复。快照或底图配置保存失败阻止退出。源文件保存、另存及数据库提交仍需明确操作。

- 不支持 GDB；WKT Z 和 GeoJSON XYZ 自动识别并保留高程；地图移动已有顶点保留其高程，已有二维图层新增要素保持 XY，空新建或含高程图层新增要素默认 Z=0；4326、4490、3857 转换仅变换 XY，高程原值保留，不进行垂直基准换算。M/ZM、GeometryCollection 和特殊几何拒绝导入或写入。GeoJSON 可明确选择二维副本，不修改原文件。空间分析支持 XYZ 输入输出，按 XY 计算、保留原顶点高程，未知新增点 Z=0，详见[空间分析](docs/processing-toolbox.md)。XY CSV 和 SHP 导出仅支持二维；含高程数据使用 WKT 或 GeoJSON 保存。PostGIS 新表全 XYZ 使用 GeometryZ，混合二维与 XYZ 须分图层导出。
- 文件单个读写最多 100 MB；ZIP 最多 2000 条、解压数据最多 200 MB。恢复副本也受大小限制。内存放大仍受要素/顶点规模影响，未宣称 100 MB 任意文件均流畅。
- 工作模型统一为 WGS84；SHP 高层读取转到 WGS84，原投影只作为来源信息。CSV、SHP、GeoJSON 支持 4326/4490/3857，默认 4326；GeoJSON 默认输出 RFC 7946 的 4326；也支持含传统 `crs` 标记的 4490/3857 导入导出。无标记文件默认 4326，可在导入窗口明确选择来源坐标系；显式选择与文件标记冲突时拒绝导入。4490（CGCS2000）与 WGS84 采用近似经纬度转换，不含历元、七参数或格网改正，不适用于测绘级基准转换。3857 输出拒绝超出 ±85.05112878° 的纬度，不静默裁切。不承诺任意工程 CRS。
- 超安全范围整数及高精度小数属性转为字符串，GeoJSON 再导出保持文本类型；普通安全数值保留数值类型。JSON 属性编辑采用无损解析后同一规则，不能承诺原始格式完全保真。
- CSV 属性默认文本，不提供完整字段 schema 设计器或 NULL 规则配置；CSV 空字符串与 NULL 不保真。改变输出几何模式会移除已识别的旧几何列，避免留下过时数据。
- 属性表为本地分页和搜索；PostGIS 读取最多 10 万条，geometry 可选当前地图范围，尚无数据库游标分页。界面标记读取上限，不能把当前结果当全表。
- PostGIS 逐行处理查询结果，包含完整提交基线的响应最多 100 MiB；超限整体拒绝，不返回缺少基线的部分记录。单行的驱动解码与服务端缓冲峰值不由该输出预算保护。MySQL 原有 16 MiB 限制保持。两引擎各最多 8 个连接，连接间请求隔离，同连接排队最多等待 35 秒；断开立即移除连接注册，排队请求失效，执行中的事务仍按原有超时边界结束。
- PostGIS 文本 WKT 来源可选 EPSG:4326（默认）、4490、3857，读取转换至工作坐标，几何提交转换回来源坐标。geometry 中 SRID=0 的记录按 4326 解释，已有非零 SRID 保留；不自动批量改写库内 SRID。
- PostGIS 新表采用 `id bigint identity + properties jsonb + geom geometry(Geometry,4326)`，不展开字段，不覆盖已有表；不支持 geography、数据库结构管理或任意 SQL。
- 本地检查几何结构，不执行完整拓扑修复；数据库提交使用 ST_IsValid。数据库连接、TLS、真实约束和并发集成仍需用户提供指定测试环境后验证。
- 退出恢复使用私有目录快照，不存密码。数据库来源恢复为本地 GeoJSON 副本，不能自动提交回原表。
- 公共 OSM 底图没有 SLA，不支持离线预取；本地数据不上传到瓦片服务，但底图请求会暴露视窗范围。

## 开发与验证

使用 Node.js >=22.13、pnpm 8.10、Rust MSVC 与 Visual Studio C++ Build Tools。工程文件位于 `F:\Workspace\Repos\个人项目\zGIS`。

```powershell
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
pnpm smoke
pwsh -File scripts/build.ps1
```

开发地址为 `http://127.0.0.1:1421`。浏览器仅用于前端验证，原生文件与数据库入口需要桌面运行。`pnpm smoke` 需要先运行 dev，使用已安装 Edge；fixtures 由测试脚本生成，不访问用户数据。

后端单测可执行 `cargo test --manifest-path src-tauri/Cargo.toml --lib --locked`，需先载入 `scripts/msvc-environment.ps1`。打包脚本显式载入 MSVC，防止 Git 的 link.exe 抢占。Cargo.lock 和 pnpm-lock.yaml 都提交，构建、截图与测试数据在 output/target，不提交。

接口见 [src-tauri/IPC.md](src-tauri/IPC.md)。最初设计见 [zGIS技术方案](../../../Deliverables/zGIS/zGIS技术方案.md)，实现边界以本 README 为准。数据库的 AI 直接操作仍遵守工作台 DBX 入口，应用数据层不提供旁路工具。

图层区为统一图层树，首次启动为空。空白处右键新建分组、新建文件、添加文件图层、添加Mysql表图层或添加PostGIS表图层；文件入口打开文件并添加图层；数据库入口从已配置数据源选择表，未配置对应数据源时置灰。分组右键新建、添加的图层进入该组。拖动可调整叠放顺序、进出分组，列表上方对应地图上方；分组支持嵌套、显隐和折叠。恢复副本保存树结构，并兼容旧版数组快照。

SHP「另存为」选择目标文件夹，输出同名 SHP、SHX、DBF、PRJ、CPG，不打包 ZIP；任一同名目标存在时拒绝保存。其他文件的另存为保留扩展名与来源坐标系，不覆盖已有文件。格式转换使用「导出为」。

图层右键仅提供“设置别名”“重命名”“移除”。别名用于图层树、当前图层标题、工具箱、MCP 和导出默认名，独立于来源文件名。“重命名”同步修改已打开来源的磁盘文件名，保留扩展名；SHP 同步处理现有 SHP/SHX/DBF/PRJ/CPG，ZIP 修改整个压缩包名。检测外部修改和同名冲突，失败回滚，不覆盖已有文件。未保存、恢复副本、浏览器和 PostGIS 图层无有效本机文件句柄，不能直接重命名来源文件；可先另存为。别名在文件重命名后保留。

分组右键支持新建子分组、重命名、新建文件、添加文件图层、添加Mysql表图层、添加PostGIS表图层、解散和删除。解散将直接子节点移至根层，保留子分组结构和顺序；删除经确认后递归移除全部子分组及图层，丢弃未保存修改，但不删除磁盘文件。正在编辑的后代图层必须先退出编辑。拖动和 Alt+方向键仍可调整排序，显隐复选框和折叠箭头保留。
